# 隐喻库（Motifs）：内容关系 → 视觉隐喻

> H 期新增（设计依据：`docs/design/theme-expression-stack.md` D5、handover §5.2）。
> 解决的问题：AI 面对内容关系默认收敛到最平庸的呈现——所有柱图都增长、数字都 count-up、对比都是左右分栏、流动都是箭头。本库按**内容关系**枚举发散的视觉隐喻，供 SKILL.md 呈现发散步（Step 1 页计划表"呈现发散"列 / Step 4 关键页）查询。

**用法**：关键页动笔前，对该页关键内容块先写 3 个**不同轴**上的呈现方案（差异轴：尺度 / 隐喻 / 维度 / 动静 / 材质），再选定。本库是隐喻轴的主要候选源。

**纪律**：

- 隐喻必须**忠实于内容关系**——天平两端失衡程度要与数据一致，年轮圈数就是年数。隐喻是修辞，不是许可证；数据真实性红线不变（SKILL.md 质量红线）。
- 选定隐喻后，视觉语言落到既有机制上：构图谱系（components.md §11）、结构族与皮肤、图表 14 配方（charts.md）、动效 recipe（motion.md）——隐喻不产生新机制，只重排既有词汇。
- 隐喻与主题气质有亲和关系（每条的"亲和"列）；主题 G8 构图倾向优先于本库亲和标注。
- 枚举的对象是隐喻，不是版式——版式自由度不变（第一性原则 2）。

## 对比（A vs B）

- **裂屏对开**：两半色场对撞，中间一道缝。谱系：裂屏对开。亲和：dramatic/professional。禁忌：两项信息量悬殊时弱侧被压死（改天平）。
- **天平**：中央支点，两侧砝码 = 数值，梁的倾角即结论。结构：轴与节点变体。亲和：professional/calm。禁忌：数值差 <10% 时倾角不可读。
- **拔河**：一根绳、双向拉力箭头、中点 marker 的偏移量示优势。亲和：playful/dramatic。禁忌：严肃财务/合规内容（戏谑感）。
- **赛道**：同一起跑线、多条终点不同的水平道（bar race 的静态化）。结构：H-Bar 变体。亲和：professional/techy。适合 3 方以上对比（裂屏/天平只装两项）。
- **镜像**：同一图形左右镜像、两侧填充不同值——强调"同构不同命"。亲和：editorial/calm。
- **前后对照**：before/after——左灰阶右全彩、左虚线右实线。亲和：editorial。适合"改造前后"叙事，不适合多方对比。

## 增长 / 变化

- **柱上升**：默认解。用它可以，但要能说清为什么别的隐喻不合适（发散步的意义就在这）。
- **阶梯**：台阶 = 阶段，每阶一个里程碑。结构：轴与节点变体。亲和：professional。适合"分阶段的确定性增长"，不适合连续数据。
- **年轮**：同心环 = 年度，半径 = 量级。亲和：calm/editorial。适合长时间跨度（≥5 年）与"沉淀"叙事；禁忌：精确读数需求。
- **潮汐线**：面积图 + 水位参考线，涨落皆可见。charts.md 面积配方 + 标注层。亲和：calm/editorial。适合有回撤的真实曲线（增长不是直线时用它反而更可信）。
- **藤蔓生长**：draw-line 曲线为主干，节点叶片 = 里程碑。亲和：calm/playful；与 D3 手绘系、C2 植物园主题天然同构。

## 流程

- **管道**：一条粗管贯穿，段间阀门/仪表 = 环节状态。亲和：techy/professional。
- **河流**：支流汇入干流，河宽 = 流量。亲和：calm。适合多源汇聚型流程（不适合严格串行）。
- **接力**：棒次交接——每段一个跑者剪影位的节点，交接处是重点。亲和：dramatic。适合强调"交接风险"的流程。
- **渗透过滤**：多层介质逐层过滤，杂质留在层间。亲和：professional。漏斗（charts.md 定量漏斗）是它的量化版。
- **循环**：回环（莫比乌斯意象）、箭头成环。结构：闭环族。亲和：全气质。禁忌：伪循环——内容其实是单向的就不要画环。

## 数字呈现

- **巨字直排**：不用动效，字号即冲击（≥8:1 对比档 + 字重立场）。亲和：editorial/dramatic。最克制也最强硬的第一候选。
- **count-up**：滚动计数。亲和：techy/dramatic。禁忌：连续多页使用（配额指纹病）；精度敏感的数字（小数/比率变化小）滚动无感。
- **翻牌**：split-flap 时刻表意象——静态近似：数字卡在上下两半的卡片里，中线缝合。亲和：playful/techy；与"时刻表"类世界主题同构。
- **刻度盘 / 仪表**：ring 环形进度 + 指针/刻度。charts.md Progress/ring。亲和：professional/techy。适合"达成率/水位"，禁忌：非百分比语义的数字硬套仪表。
- **印戳**：数字像盖章压上纸面（scale-pop 落点）。亲和：playful/dramatic。适合"结果已定"的结论页。

## 层级

- **金字塔**：分层切面，面积 = 规模。禁忌：面积不成比例时改列表——金字塔的视觉谎言是老病。
- **同心圆**：内核到外层（洋葱模型）。亲和：calm/editorial。
- **树 / 分类学**：干—枝—叶，与 C2 植物园主题同构（叶脉分叉母题可直接收编）。
- **地层剖面**：地质岩层 = 时间或层级沉积。亲和：calm/editorial。适合"历史堆叠成的现状"。

## 组成

- **堆叠条**：一根 100% 条切段（H-Bar 堆叠配方）。比饼图精确，是默认首选。
- **马赛克墙**：方格墙着色比例 = 占比（华夫格）。亲和：professional/techy。适合百分比整数。
- **调色盘 / 配方表**：成分列成色票 + 占比注记。亲和：editorial/playful；与出版/奶油系主题同构。
- **饼/环图**：仅 ≤4 段时用（charts.md Donut 纪律不变）。

## 因果

- **多米诺**：一列骨牌依次倾倒，首张 = 因。亲和：dramatic。适合链式传导（"蝴蝶效应"叙事）。
- **齿轮组**：啮合转动 = 机制咬合。亲和：techy。禁忌：纯装饰性滥用（齿轮必须对应真实环节）。
- **涟漪**：中心事件，同心波环 = 影响圈层扩散。亲和：calm。适合"影响半径"叙事。
- **杠杆**：小力撬动大物——支点位置 = 关键变量。亲和：professional。适合"关键抓手"论证。

## 时间

- **轴与节点**：默认时间轴（components.md 结构族）。用它可以，同样要求发散步给过理由。
- **日历格**：月历网格，事件落在格子里。亲和：professional。适合排期/节奏类内容。
- **行程单 / 车票**：一段旅程一张票——站名、时刻、检票口都是信息槽位。亲和：playful/editorial。
- **胶片刻度**：齿孔 = 帧，帧号 = 时刻；与 D2 暗房主题同构（齿孔母题可直接收编）。
