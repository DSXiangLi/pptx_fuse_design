# 图表配方（Charts v2）

> v2（2026-09-19，视觉纵深 F3）：类型从 5 扩为 14——基础五（H-Bar / Column / Line / Donut / Progress，v1 保留）+ 扩展九（堆叠柱/条、分组柱、面积、瀑布、散点/气泡、雷达、斜率、漏斗、热力表格）；新增**标注层规格**（§3，每个配方必须带）与**系列色 8 档推导**（§2）。
> 全部纯 HTML/CSS/内联 SVG 实现，零依赖零 JS（入场动效复用骨架的 `.in-view` 机制）。
> 高复杂度参照实例见 `../gallery/index.html` 第 16–24 页（每扩展类型一页，含完整标注层）——配方抬下限靠规则，画廊抬下限靠"可以抄的具体样子"。

## 1. 硬规则

1. **数据真实**：没有真实数据就不用图表（见 components.md §0）；示例数据必须在页面上标明"示例/scenario"口径；
2. **几何按值计算**：条宽/柱高/扇区角/坐标一律由数值算出（`calc(var(--v) / var(--max) * 100%)` 思路），禁止目测拍脑袋；
3. **安全换算**：数据 → 几何前做 clamp（0–max 区间）、防除零（max=0 时整组不渲染图表只渲染文字）、防空数组；
4. **图文一致**：填完真实数据后，本页的 insight / 结论文案必须一并改写，不留占位结论；
5. **可编辑分层**（契约级）：SVG/几何整体 `data-editable-skip`；图例标签、轴标签、**标注文字** `data-editable`；**数值列与几何绑定——用户就地改数字图形不会变，数值修改走 AI 流程**（详见 editing-contract.md §图表元素的分层）；
6. **标注层必带**（F3 起）：每个图表页至少带一种 §3 标注——"能读数"靠几何，"讲故事"靠标注。

## 2. 主题绑定（chart token）

图表颜色不写死，一律引用主题变量。基础色板之外，图表专用 token 按统一规则从主题推导（canonical 定义见 themes.md §图表 token，逐字复制进 `:root`）：

| token | 用途 |
|---|---|
| `--chart-grid` | 网格线/基线（ink 的 12% 透明度） |
| `--chart-label` | 轴/图例/标注标签（ink 的 60%） |
| `--chart-series-1..8` | 系列色 8 档：1–4 = accent → accent 55% → accent 32% → ink 18%（v1 冻结）；5–8 = ink 62% / accent 16% / ink 40% / ink 24%（F3 扩，明暗交错续排） |
| `--chart-bar-radius` | 柱/条圆角（杂志系 0，瑞士系 0-2px，个性系 ≤8px） |
| `--chart-stroke` | 折线宽度（2–3px） |

**系列色使用纪律**：8 档是硬上限。系列数 >4 时先自问能否合并（尾部并"其他"、维度下钻拆页）；超过 8 系列说明选型错了（改热力表格 / 斜率图 / 拆页）。堆叠图同一柱内相邻段的明度差由交错阶梯天然保证，不自行调配。暗色页系列色与底色拉不开时逐档镜像派生（mix 目标从 paper 换成 ink，见 themes.md）。

## 3. 标注层规格（Annotation Layer，F3 核心）

标注 = 文字元素，不进几何（契约 v4 标注修饰件条款的图表层落位）。四种标注覆盖"讲故事"的全部基本动作：

| 标注 | 形态 | 几何 | 文字 |
|---|---|---|---|
| **参考线** | 均值/目标值虚线横贯绘图区 | 1px dashed，`color-mix(in srgb, var(--chart-label) 70%, transparent)`，skip | 线端上方 mono 小标签（如"均值 8.1 亿"），`data-editable` |
| **区间带** | 背景色带标一个 x/y 区间 | 矩形 `color-mix(in srgb, var(--accent) 8%, transparent)` 或 `--paper-tint`，垫底（网格与数据之下），skip | 带上沿小标签，`data-editable` |
| **数值直标** | 端点/柱顶/顶点直接标数值 | 无几何 | mono + `font-feature-settings:"tnum"`，`data-editable`（数值层：改数不改几何） |
| **注释旗标** | 事件注释 = 旗标盒 + 引线 | 引线 1–1.5px 实线，skip | 旗标盒内文字 `data-editable` |

统一规范（硬规则）：

1. **标注文字一律在 SVG 外的 HTML 覆盖层**承载（图表容器 `position:relative`，标注绝对定位），`data-editable`；引线、参考线、区间带几何 `data-editable-skip`；
2. **标注配色从 token 推导**：文字默认 `var(--chart-label)`；旗标盒走容器规格四档明度（components.md §12——纸档 hairline 锚点为默认，同页 accent 档旗标 ≤1 且计入主题 G1 accent 预算）；参考线/引线用 chart-label 的 40–70% 透明档，**禁止用系列色画参考线**（会与数据系列混淆）；
3. **不遮数据墨迹**：引线落在数据点旁边不压柱/线主体；旗标避让极值点与密集区；
4. **数值直标只标关键点位**（端点/极值/焦点/起止），全点位标注 = 没有重点；
5. **密度适配**：low 档一页只留一种标注（优先端点数值直标）；high 档可叠 2–3 种；注释旗标每图 ≤2。

## 4. 配方 · 基础五（v1 保留）

### H-Bar 横条图

三列 grid：标签（固定宽）| 轨道 | 数值（等宽数字 `font-feature-settings:"tnum"`）。

```html
<div class="bar-row">
  <span class="bar-label" data-editable>线上渠道</span>
  <span class="bar-track" data-editable-skip><span class="bar-fill" style="--w:84%"></span></span>
  <span class="bar-value" data-editable>84%</span>
</div>
```

`.bar-fill{width:calc(var(--w));background:var(--chart-series-1)}`，入场 `transform:scaleX(0)` → `.in-view` 时 `scaleX(1)`，`transform-origin:left`。
**标注搭配**：目标值竖参考线（横条图为纵向虚线）+ 焦点条数值直标。

### Column 柱状 / KPI Tower

不等高竖条，`style="--h:36%"` 传高度（`height:calc(var(--h))`，从底部 `scaleY` 拉起入场）。负值场景：以 zeroY 基线分上下两段，不要把负值画成正柱。
**标注搭配**：均值横参考线 + 柱顶数值直标（只标焦点柱）。

### Line 折线

内联 SVG `viewBox="0 0 1000 420"` + `preserveAspectRatio="none"` 外层控比：`polyline` 折线 + `circle` 数据点 + 4 条网格线。坐标在生成时由数据换算成 viewBox 坐标（y 轴留出 10% 头部余量）。SVG 整体 `data-editable-skip`，坐标轴文字在 SVG 外用 HTML 承载（可编辑）。
**标注搭配**：事件注释旗标（拐点/突变点）+ 端点数值直标。

### Donut 环图

SVG 圆环分段：`stroke-dasharray="弧长 周长-弧长"` + `stroke-dashoffset` 累加偏移 + `rotate(-90)` 起点归顶。**图例（标签+数值）用 SVG 外的 HTML 列表承载**（可编辑），圆心可放总计数字（`data-editable`，但与几何绑定的数值修改走 AI 流程——页面上用批注即可）。
**标注搭配**：图例即数值直标；焦点扇区用注释旗标引出。

### Progress 进度条

纯 HTML：`width:X%` 的填充条 + 标签。适合完成度/目标进度，3–6 条为宜。
**标注搭配**：目标位刻度线 + 数值直标（自带）。

## 5. 配方 · 扩展九（F3 新增）

每配方按七件规范精简版组织：身份 / 数据形态 / 几何规则 / 密度适配 / 可编辑分层 / 反模式 / 验收要点。参照实例：gallery 第 16–24 页（一页一型）。

### 5.1 Stacked 堆叠柱/条

**身份**：总量 + 构成同时成立——每根柱是总量，分段是构成。可区分性：读者既要问"总共多少"也要问"由什么组成"。
**数据形态**：`categories[] × series[]`（2–4 系列 × 3–6 类目），系列间可加、量纲一致。
**几何规则**：柱内分段从基线累计堆叠，`height = v / maxTotal * 轨道高`——**max 取各柱合计的最大值，不是单段最大值**；段色取 series-1..N（相邻段明度差由交错阶梯保证，§2）；柱顶直标合计值。
**密度适配**：low 档 2 系列 × 4 类目，只标合计；high 档 4 系列 × 6 类目，加图例 + 目标参考线。
**可编辑分层**：分段几何 skip；类目标签、图例、合计直标、标注文字 editable。
**反模式**：系列不可加（率/指数）做堆叠——堆叠的是量不是率；系列 >4 不分段改分组或合并"其他"。
**验收要点**：各柱分段高度之和 == 柱总高（±2px）；柱顶直标 == 各段数值之和；参照实例 gallery p16。

### 5.2 Grouped 分组柱

**身份**：同一类目下少数系列的并排对照——对照关系在系列间，不在加总。
**数据形态**：`categories[] × series[]`，**恰好 2–3 系列**（3 系列以上分组柱变篱笆，改堆叠或斜率）× 3–5 类目。
**几何规则**：组内柱并排等宽，`组宽 = 系列数 × 柱宽 + 组内间距`，组间距 ≥ 1.5× 组内间距；柱高 `v / max * 轨道高`（max 取全表最大值，跨组同尺度才可对照）。
**密度适配**：low 档 2 系列 × 3 类目；high 档加图例 + 区间带（标焦点类目组）。
**可编辑分层**：柱几何 skip；类目/系列图例、柱顶数值直标 editable。
**反模式**：4 系列以上硬分组；组内间距 ≥ 组间距（组界消失，读者分不清类目）。
**验收要点**：同组柱同底对齐、同尺度；图例色与柱色一一对应；参照实例 gallery p17。

### 5.3 Area 面积图

**身份**：折线的量感强化——趋势之下有"积累"语义（存量、累计、体量）。可区分性：读者关心曲线下的总量/体量，不是单点读数。
**数据形态**：单系列（至多 2 系列，且须有包含关系）× 8–24 时间点。
**几何规则**：折线闭合成面——path 沿折线后闭合到基线，填充 `color-mix(in srgb, var(--chart-series-1) 16%, transparent)`，描边 `var(--chart-series-1)` + `--chart-stroke`；y 轴同 Line（留 10% 头部余量）；2 系列时后系列透明度再减半防遮盖。
**密度适配**：low 档单系列只标端点；high 档加区间带（标事件窗口）+ 旗标。
**可编辑分层**：path/网格 skip；轴标签、端点直标、区间带与旗标文字 editable。
**反模式**：多系列交叉面积图（互相遮盖，改 Line）；无积累语义的序列强行面积化（量感造假）。
**验收要点**：面积闭合路径底边贴基线；参照实例 gallery p18。

### 5.4 Waterfall 瀑布图

**身份**：从 A 到 B 的增减分解——桥接两个总量，中间每段是一次增减。可区分性：首末柱是存量（从基线起），中间柱是流量（悬空，从前柱顶/底起）。
**数据形态**：`起点值 + deltas[]（带正负号）+ 终点值`，满足 `起点 + Σdeltas == 终点`（硬约束，生成时验算），中间段 3–6 个。
**几何规则**：柱 `bottom = min(累计前, 累计后) / max * 轨道高`，`height = |delta| / max * 轨道高`；首末柱从基线 0 起（墨档/ink 填充），正增量 series-1、负增量 series-4（ink 浅阶）；相邻柱间画累计水位连接线（1px dashed，skip）。
**密度适配**：low 档 3 段只标首末值；high 档 6 段全数值直标 + 异常段旗标。
**可编辑分层**：柱/连接线 skip；类目名、每段数值直标（含正负号）、旗标文字 editable。
**反模式**：增减不收敛（起点+增量≠终点）；负值段画成从基线向上的正柱（方向造假）。
**验收要点**：逐柱累计水位衔接（前柱累计顶 == 后柱悬起端，±2px）；终点柱高 == 起点+Σdeltas；参照实例 gallery p19（Playwright 几何抽验对象）。

### 5.5 Scatter/Bubble 散点/气泡图

**身份**：二维定位（散点）+ 第三维体量（气泡）——个体在双指标坐标系里的分布与离群。
**数据形态**：`points[]`：(x, y, size?, label?)，8–20 点；size 是第三维真实数值（营收/规模），没有第三维就用散点不吹气泡。
**几何规则**：x/y 线性映射到 viewBox（两轴各留 10% 余量）；气泡**半径 r = √(v/max) × rMax**（面积与值成正比，半径开方——直接线性映射半径会夸大差异 4 倍）；rMax ≤ 绘图区短边 / 12。
**密度适配**：low 档散点 + 双均值参考线；high 档气泡 + 象限标签 + 焦点旗标。
**可编辑分层**：点/参考线 skip；轴标题、象限标签、焦点点标注 editable；单点标签只标焦点（≤3 个）。
**反模式**：气泡半径线性映射；给所有点贴标签（标签云盖过分布形态）。
**验收要点**：抽 2 点验证坐标 == 数据线性映射；焦点气泡是 accent 唯一点色；参照实例 gallery p20。

### 5.6 Radar 雷达图

**身份**：多维度画像对照——一个（或两个）对象在 4–8 维上的形状。可区分性：读者关心"形状"（哪维鼓哪维瘪），不关心单维精确读数。
**数据形态**：`dims[]`（4–8 维，0–max 同尺度评分）× **1–2 个对象**（3 个以上形状糊成一团，改 H-Bar 矩阵）。
**几何规则**：顶点 `r_i = v_i / max × R`，角度 `θ_i = -90° + i × 360°/N`（首维朝上，顺时针）；网格环取 max 的 25/50/75/100% 四圈（skip）；两对象时主对象 accent 填充 25% + 描边，次对象 ink 描边低透明不填充。
**密度适配**：low 档单对象不标数值；high 档双对象 + 焦点维数值直标 + 差异维旗标。
**可编辑分层**：多边形/环/轴 skip；维度标签（HTML 环绕排布）、图例、数值直标 editable。
**反模式**：维度量纲不齐（分、元、% 混排）不归一化就上雷达；维度 >8（形状不可读）。
**验收要点**：抽 2 顶点验证 `r_i ∝ v_i`（顶点坐标与数据一致，Playwright 可验）；维度标签环绕不压形状；参照实例 gallery p21。

### 5.7 Slope 斜率图

**身份**：两个时点间的排名/数值迁移——每条斜线是一个对象的"从到"。可区分性：中间时刻不存在或不重要（有中间过程就用 Line）。
**数据形态**：`items[]`：(label, v1, v2)，4–8 条；恰好两个时点。
**几何规则**：左右两条竖轴，y 共用同一线性尺度（`y = H × (1 - (v - min) / (max - min))`，min/max 跨两列合取）；连线斜率即变化方向；上升/下降用色只给一个焦点例外——**焦点线 accent，其余 ink 阶梯降透明**，方向靠斜率本身表达不靠双色。
**密度适配**：low 档 4 条只标端点值；high 档 8 条 + 排名变化旗标（"上升 2 位"）。
**可编辑分层**：斜线/轴 skip；两端"名称 + 数值"标签 editable。
**反模式**：端点标签重叠不处理（相近值的标签沿轴微错开，禁用引线斜拉）；3 时点以上用斜率图（中间拐点丢失）。
**验收要点**：同值同高（v1 相等的条目左端点对齐）；标签无重叠（渲染校验覆盖）；参照实例 gallery p22。

### 5.8 Funnel 漏斗图（定量）

**身份**：单流向逐级转化的定量漏斗——级宽 ∝ 留存值。与 components.md 的 `sequence-funnel`（流程骨架，可不带数值）的分工：**带真实转化率数据走本配方（chart 族），纯流程叙事走 sequence-funnel（结构族）**。
**数据形态**：`stages[]`：(label, value)，3–5 级，**数值单调不增**（硬约束，静态可验）。
**几何规则**：级宽 `w = v / v1 × 最大宽`、居中堆叠；**设最小宽度下限（≥ 最大宽 × 6%）保可读，启用下限时须在页面上注明"末级宽度经下限调整"**；级间标转化率（vᵢ₊₁/vᵢ）。
**密度适配**：low 档 3 级只标首末；high 档 5 级 + 级间转化率 + 最大断点旗标。
**可编辑分层**：漏斗几何 skip；级名、数值、转化率、旗标文字 editable。
**反模式**：数值乱序（回流/分叉不是漏斗）；宽度下限静默生效不声明。
**验收要点**：数值单调不增；级宽 ∝ 值（下限声明的末级除外）；参照实例 gallery p23。

### 5.9 Heatmap Table 热力表格

**身份**：矩阵密度的模式扫描——行 × 列交叉处的强弱分布。可区分性：单元格多到条形图画不下（≥12 格），读者找的是"哪里深哪里浅"的模式而非单格读数。
**数据形态**：`rows[] × cols[]`（3–6 × 4–8）的单一量纲矩阵。
**几何规则**：单元格底色 `color-mix(in srgb, var(--chart-series-1) X%, var(--paper))`，**X = 8 + round(v / max × 72)**（8% 起步保底可见、80% 封顶留文字对比）；格内数值直标（tnum），X ≥ 48% 的格子文字反白（`--accent-on`/`--paper`）；色阶图例条（min→max 渐阶 + 两端数值）。
**密度适配**：low 档 3×4 不标格内数值（纯色块扫描）；high 档 6×8 全标 + 极值旗标 + 行/列均值附列。
**可编辑分层**：单元格底色是容器（不标 editable）；格内数值、行/列表头、均值、旗标文字 editable；色阶图例几何 skip。
**反模式**：彩虹色阶（双色以上插值 = 引入主题外颜色，违反 token 纪律）；用热力表格装 2×3 小矩阵（用 compare/quadrant）。
**验收要点**：格子底色 X% 与数值单调一致（数值大 ⇒ 色深）；极值格有旗标；参照实例 gallery p24。

## 6. 动效与降级

- 入场：骨架 `.in-view` 触发（scaleX/scaleY/描边生长），时长 300–600ms，同页只让主角图表做生长动画；堆叠/瀑布的逐段生长用阶梯延迟（`--d`），不超过 3 段错峰；
- `prefers-reduced-motion`：直接终态（骨架红线已保证 `.reveal` 机制；图表自带动效类要同样遵守）；
- 数字滚动（count-up）走骨架运行时 recipe（`data-anim="count-up"`），图表几何本身保持零 JS。
