# 组件参考（Components v3）——构图谱系 × 结构族 × Item 皮肤 × 参数变体

> 信息图 = **结构族 × Item 皮肤 × 参数变体**，主题 token 贯穿染色；页面 = **构图谱系**（§11）承载信息图与其余内容。
> 结构族与皮肤是有限枚举（可静态校验），参数变体由规则推导（不枚举）——衍生能力 = 6 族 × 6 皮肤 × 变体，枚举对象只有十几个。
> 组件是"配方"，不是模板类库：只给结构骨架与规则，具体样式由当前主题 token 与当页构图决定。
> v3 新增（视觉纵深 F2，依据 `docs/design/visual-depth.md` 要素 5/6/8）：**§11 构图谱系**（页面构图层，在族选型之前决定整页骨架与节奏）与 **§12 容器规格**（四档明度 / 直角纯色 / accent 单焦点 / 灰底低对比）。§0–§10 的结构族、皮肤、适配矩阵与断言全部保留，编号不变。
> 设计依据：`docs/design/infographic-system.md`（迭代 D）+ `docs/design/visual-depth.md`（F2）；新族/新皮肤入库走 `docs/research/sota-visual-languages.md` 七件规范。
> 高复杂度参照实例见 `../gallery/index.html`（画廊 deck：每族 × 代表皮肤一页，含连接件语义层次 / 数据墨迹 / 标注层 / 材质叠印）——配方抬下限靠规则，画廊抬下限靠"可以抄的具体样子"。
> 背景配给纪律（skeleton v4）：组件/材质叠印（`data-stylize`、质感层）默认只在仪式页启用；正文页背景保持纯色，启用质感须逐页 `.texture-on` 显式声明——详见 `motion.md` §4 使用规则。

## 0. 选型三步与数据形态自证（硬规则）

### 0.1 三步选型

顺序不可颠倒：**内容关系 → 结构族 → Item 皮肤**。（页面层在信息图选型之前还有一次构图决策：本页属于哪个构图谱系，见 §11——谱系管整页，族管信息图，两者组合不互替。）

1. **内容关系**：本页内容条目之间的真实关系是什么（并列 / 顺序 / 对比 / 层级 / 关系连接 / 定量）？从内容里读出来，不从"想画什么图"出发；
2. **结构族**：按关系选族、按项数与气质选骨架（§1）；
3. **Item 皮肤**：按主题气质与单元内容选皮肤（§2），过 §3 适配矩阵。

### 0.2 数据形态自证清单（动笔前逐项回答）

选定结构族**之前**，内容必须先能填入该族的数据字段形态。清单即护栏：

| 结构族 | 数据字段形态 | 自证问题 |
|---|---|---|
| `list` | `items[]`：label / desc? / value? / icon? | "条目打乱顺序，意思变不变？"——不变才是并列 |
| `sequence` | `sequences[]`：label / desc?（含 order） | "第 2 步能不能放到第 4 步前面？"——不能才是顺序 |
| `compare` | `compares[]`：二元对比恰好两个根 | "是不是恰好两边 / 恰好四象限？" |
| `hierarchy` | `root` 递归：label / children[] | "每个子项是不是只属于一个父项？" |
| `relation` | `nodes[]` + `edges[]`（A —标注→ B） | "节点之间的关系是不是本页的主角？" |
| `chart` | `values[]`（引用 charts.md） | "这些数字有没有真实出处？" |

【硬规则】三条：

1. 并列数据不进 `sequence`，二元关系不进 `list`，层级数据不压平进 `list`——关系造假比没有图更糟；
2. 纯定性论断严禁编造数字塞进 stat 皮肤或 chart 族（"96% 的用户喜爱"没有出处就是撒谎）；
3. 项数超出骨架合法区间 → 换骨架、换族或拆页，不硬塞。

内容没有图示价值时，文字排版本身就是版式——不要为"丰富"而加图。

### 0.3 可静态校验断言（机器可验部分）

生成产物携带辅助标记（契约 v4 §信息图组件的分层）：信息图根元素标 `data-ig="<族>-<骨架>"`（如 `list-zigzag`）与 `data-ig-skin="<皮肤>"`，每个数据单元标 `data-ig-item`。据此可静态校验：

1. `compare-binary-cols` / `compare-vs-overlay` 的 `data-ig-item` 数 **== 2**；`compare-quadrant` / `compare-swot` **== 4**；
2. 各骨架 `data-ig-item` 数 ∈ §1 合法项数区间；
3. 族 × 皮肤组合 ∈ §3 白名单（禁止组合出现即不合格）；
4. `data-stylize` 元素必同时标 `data-editable-skip`；
5. `sequence-funnel` 带数值时，数值单调不增；
6. 标注修饰件：引线/箭杆 `data-editable-skip`，标注文字 `data-editable`。

## 1. 结构族（六族）

每族按七件规范的精简版组织：**身份 / 骨架 / 量化规则 / 密度适配 / 可编辑分层 / 反模式 / 验收要点**。geo 族缓建（等真实需求，见设计文档 §9）。

### 1.1 `list` 并列族

**身份**：几个地位平等、顺序无关的条目并排呈现。可区分性：条目打乱顺序语义不变（变了请去 sequence）。

**骨架**：

| 骨架 | 构图 | CSS 结构要点 | 合法项数 |
|---|---|---|---|
| `row` | `A │ B │ C` 单轴排开（横排或纵行） | flex/grid 单轴，行间 1px hairline 分隔 | 3–5 |
| `grid` | `┌─┬─┐ └─┴─┘` 2×2 / 2×3 矩阵 | grid 等分列；hairline 或留白分区 | 4–6 |
| `zigzag` | 左右交错落位，中间可留轴 | 两列 grid，奇偶项分别靠左右对齐 | 3–6 |
| `waterfall` | 逐级下探的错位台阶（仅节奏，无升降语义） | 每行 `margin-inline-start` 递增 | 3–5 |
| `pyramid` | 上窄下宽叠层（宽度差是视觉，不是数值比例） | 逐层定宽、居中叠放 | 3–5 层 |

**量化规则**：项数必须在区间内；不足下限（<3）说明内容撑不起信息图，退回纯文字版式；超上限换 `grid` 密排或拆页。
**密度适配**：low 档只留 label（省略 desc），项数取区间下限；high 档 label+desc 全配，项数可到上限。
**可编辑分层**：Item 文字 `data-editable`；分隔线、序号装饰、背景形 `data-editable-skip`。
**反模式**：把有先后的流程塞进 list（顺序信息丢失）；为凑满 grid 格数硬拆条目；卡片网格全 deck 复用（SKILL.md 默认规则：同 deck 卡片墙版式最多一次）。
**验收要点**：渲染无溢出无重叠；项数 ∈ 区间（静态可验）；条目打乱顺序后语义不变（人工判断）。

### 1.2 `sequence` 顺序族

**身份**：方向性顺序——步骤、流程、历程。可区分性：顺序不可打乱，节点间有"然后"。

**骨架**：

| 骨架 | 构图 | CSS 结构要点 | 合法项数 |
|---|---|---|---|
| `steps` | `①─②─③` 编号节点单轴串联 | 节点 flex/grid 排开，节点间连线或箭头（装饰层） | 3–5 |
| `timeline` | 一条主轴 + 节点（时间点 + 事件） | 主轴 hairline，节点圆点压线，上下/左右交替落文字 | 3–5 |
| `stairs` | 逐级上升台阶（带成长/进阶语义） | 每级 `margin-top` 递减或绝对定位抬升 | 3–5 |
| `funnel` | 上宽下窄收口 | 逐层定宽居中；有数值时宽度按值比例计算 | 3–6 |
| `snake` | 蛇形折行（步骤超出一行容量时） | 多行 flex-wrap，行间折返连线 | 5–8 |

**量化规则**：项数在区间内；一般骨架超过 6 步先考虑合并或分页（snake 是容量特化，可到 8）；funnel 有数值时必须单调不增（静态可验）。
**密度适配**：low 档只留节点名；high 档每节点加一行 desc。
**可编辑分层**：节点文字 `data-editable`；连接线、箭头、节点圆点 `data-editable-skip`。
**反模式**：无真实先后的并列项排成 steps（关系造假）；funnel 数值乱序；timeline 节点塞长段文字（细节另起页）。
**验收要点**：节点序号与文案顺序一致；连线不压文字；项数 ∈ 区间（静态可验）。

### 1.3 `compare` 对比族

**身份**：二元/四元对照——前后、优劣、供需、象限定位。可区分性：内容里有明确的"两边"。

**骨架**：

| 骨架 | 构图 | CSS 结构要点 | 合法项数 |
|---|---|---|---|
| `binary-cols` | 左右镜像双栏，弱化一侧（降不透明度）突出另一侧 | 两列等宽 grid，中缝 hairline | **恰好 2** |
| `quadrant` | 2×2 象限，两轴定位 | 十字轴 + 四象限格 | **恰好 4** |
| `swot` | 2×2 带语义（优势/劣势/机会/威胁），quadrant 的语义特化 | 同 quadrant，象限标题固定语义 | **恰好 4** |
| `vs-overlay` | 同尺寸两块叠压对峙，中间 VS 分割 | 两块重叠/错位定位，中央徽章分隔 | **恰好 2** |

**量化规则**：binary / vs 恰好两项、quadrant / swot 恰好四项是**硬断言**（静态可验）；三边对比不许塞 binary-cols（换 `list/row`）；两侧信息量须相当。
**密度适配**：low 档每侧只给结论行；high 档每侧 2–4 个对照点，槽位结构对称。
**可编辑分层**：两侧全部文字 `data-editable`；VS 标、中缝分割线、轴装饰 `data-editable-skip`。
**反模式**：两侧信息量悬殊（弱化侧空洞）；对比点不明确（为对称而对称）。
**验收要点**：项数硬断言通过（静态可验）；两侧槽位结构对称、信息量相当（渲染 + 人工）。

### 1.4 `hierarchy` 层级族

**身份**：层级包含——父子、体系、归属。可区分性：每个子项只有唯一父项（有交叉归属请去 relation/network）。

**骨架**：

| 骨架 | 构图 | CSS 结构要点 | 合法项数 |
|---|---|---|---|
| `tree` | 根在上（或左），逐层向下（右）展开 | 层 = flex 行/列，父子连线（装饰层） | 2–4 层，每层 ≤6 节点 |
| `mindmap` | 中心主题 + 辐射分支 | 中心节点绝对定位居中，分支环绕 | 中心 1 + 分支 4–7 |
| `concentric` | 同心圆层（内核 → 外延） | 嵌套圆环（border 圆），层标签压环或环外引线 | 2–4 层 |

**量化规则**：每层节点 ≤6，超了先合并同类项；深度 >4 层拆页；concentric 层数 2–4（静态可验）。
**密度适配**：low 档只标层名/节点名；high 档节点加一行 desc。
**可编辑分层**：节点文字 `data-editable`；圆环、连线、中心装饰 `data-editable-skip`。
**反模式**：并列关系画成同心圆（无包含语义）；交叉归属画成 tree；stat 皮肤进 hierarchy（禁止组合，见 §3）。
**验收要点**：树结构无交叉连线（人工）；层数/节点数 ∈ 区间（静态可验）。

### 1.5 `relation` 关系族

**身份**：关系连接——流向、依赖、循环，**关系本身**是本页主角。可区分性：拿掉连线，本页信息就垮了。

**骨架**：

| 骨架 | 构图 | CSS 结构要点 | 合法项数 |
|---|---|---|---|
| `flow` | 节点 + 有向连线（可分支、可汇合） | 节点定位 + 连线/箭头层（SVG 或 border 三角） | 3–6 节点 |
| `network` | 节点 + 无向连接网 | 节点散布定位，连线层垫底 | 4–8 节点 |
| `circle-loop` | 环形节点首尾相连闭环 | 节点绝对定位压环（圆环装饰层），箭头示向 | 3–5 节点 |

**量化规则**：每条边必须带语义——方向箭头或标注文字，无线语义的相邻不是 relation；circle-loop 节点 ≥3（少于 3 不构成循环，静态可验）。
**密度适配**：low 档只留节点名；high 档边上加标注文字。
**可编辑分层**：节点文字与边标注 `data-editable`；连线、箭头、环 `data-editable-skip`。
**反模式**：线性流程画成闭环（关系造假）；network 节点全连接成毛线团（边 >12 就该收敛）。
**验收要点**：circle-loop 节点数 ∈ 3–5（静态可验）；每条边有标注或方向（人工）。

### 1.6 `chart` 图表族

定量图表引用 `references/charts.md` v2 的 14 配方（基础五：H-Bar / Column / Line / Donut / Progress；扩展九：堆叠/分组柱、面积、瀑布、散点·气泡、雷达、斜率、定量漏斗、热力表格，均带标注层规格）；数据真实性、几何按值计算、安全换算的硬规则不变。可编辑分层：几何整体 `data-editable-skip`、标签与标注文字 `data-editable`、数值与几何绑定走 AI 流程（契约"图表元素的分层"节）。chart 族**不参与 §3 皮肤矩阵**——皮肤由配方自身承载；作为嵌套小图使用时遵守 §5 嵌套规则。

## 2. Item 皮肤（六款）

皮肤只负责"单个数据单元长什么样"，不负责布局。同一结构族换皮肤 = 换单元气质，骨架不变。

| 皮肤 | 结构骨架 | 适用场景 |
|---|---|---|
| `bare` | 纯文字：label（+desc），靠字重/字号/留白分层，无框无底 | 杂志系主题（A 系）默认；克制叙事 |
| `card` | 底色块或描边框 + 内边距：title + desc（明度档、单焦点与直角纪律见 §12 容器规格） | 瑞士系 / 圆角主题；条目需要明确边界 |
| `badge` | 编号或图标徽章 + 旁排文字 | sequence 步骤编号、list 要点 |
| `ribbon` | 色带/标签条（accent 衬底或描边），单行短文字 | timeline 节点、分类标签 |
| `stat` | mono 小标签 → 巨数（单位用 `<em>` 缩到 0.4em 并降不透明度）→ 一行注释 | 真实量化数据论证；每页只让最大的一个数字当主角 |
| `icon-line` | 线性图标（SVG 线稿）+ 标签一行 | 轻量要点、特性清单 |

皮肤通用规则：

- `stat` 的内容门槛同数据真实性硬规则：真实数据；数字控制在 2–3 位（K/M/万 简写）；
- `icon-line` 的图标统一走 `assets/` 图片契约（`data-editable-image`），线稿风格跟随主题 G7；
- 皮肤内文字（label/desc/value）全部 `data-editable`；皮肤容器、徽章底、色带、图标图形 `data-editable-skip`。

## 3. 族 × 皮肤适配矩阵

✓ 适配 · △ 慎用（需要在交付说明里给理由）· ✗ 禁止。矩阵是白名单，可静态校验（§0.3-3）。

| 族＼皮肤 | bare | card | badge | ribbon | stat | icon-line |
|---|---|---|---|---|---|---|
| `list` | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| `sequence` | ✓ | ✓ | ✓ | ✓ | △ | ✓ |
| `compare` | ✓ | ✓ | △ | △ | ✓ | ✓ |
| `hierarchy` | ✓ | △ | ✓ | ✗ | ✗ | △ |
| `relation` | ✓ | ✓ | ✓ | ✗ | ✗ | △ |
| `chart` | —（皮肤由 charts.md 配方承载，不参与矩阵） | | | | | |

禁止组合的判据：`stat` 要求"每单元一个真实量化值"，而 hierarchy / relation 的节点是结构概念不是数值；`ribbon` 的单行短条形态塞不进层级/关系节点的多行内容。

## 4. 参数变体规则（不枚举，规则推导）

变体由三条规则推导，**不产生新枚举项**：

1. **密度档**：low = 间距放宽（约 ×1.5）、省略 desc、项数取骨架区间下限；high = 间距收紧（保持 hairline 节奏）、desc 全配、项数可到区间上限。槽位字数预算折算沿用 typography.md §4，超预算精简或拆页，不缩字号。
2. **方向**：横排为默认（16:9 横画布）；项数 >5 或单元文字偏长时转纵排；zigzag / snake 自身含方向语义，不另设方向变体。
3. **项数**：取内容实际条数并落在骨架合法区间内（§1）；区间装不下就换骨架/换族/拆页——项数由内容决定，不为凑版式增删内容。

## 5. 组合与嵌套规则

- **一页一个信息图主体**（一页一意原则在信息图层的投影）；信息图旁允许配 Callout / Highlight / 标注修饰件；
- **嵌套允许一层**：信息图 Item 内可嵌 chart 族小图（如卡片内嵌迷你柱图 / 进度条）；**禁止信息图套信息图**；
- **容量分摊**：嵌套时内层占用外层的槽位预算（typography.md §4 折算不变），预算超限换结构或拆页；
- **标注修饰件**（引线标注、角标、数值旗标）：**标注 = 文字元素，不进几何**——标注文字 `data-editable`，引线/箭杆 `data-editable-skip`（契约 v4 条款）。

## 6. 风格化接口（stylize）

信息图的"fancy"很大程度来自质感而非结构：

- 主题 Schema 的 G3 texture 字段声明风格化类型（手绘 rough / 柔光 glow / 图案 / 平色 flat）与作用范围（themes.md）；
- 落码时，参与风格化的图形元素统一标 `data-stylize`（纯装饰语义，**必同时标 `data-editable-skip`**，静态可验 §0.3-4），按主题配方施加对应 CSS：rough = 不规则 border-radius + 双层错位描边；glow = 径向叠加层（复用 skeleton v3 质感槽位）；flat = 不加任何装饰（零成本）；
- **风格化由主题决定，不由单页决定**——换主题即换质感，信息图结构不变。

## 7. 页面修饰件（非信息图，保留小类）

不参与族 × 皮肤组合，作为页面级修饰独立使用：

### Callout 引用框

**骨架**：细线或留白框出的一段话 + 可选出处行。
**场景**：金句、核心论断、需要读者停下来的那一句话。
**门槛**：一段话，不是列表；一页最多一个。
**标记**：引文与出处 `data-editable`。

### Ghost 背景字

**骨架**：超大字号（画布 30vw 级）、极低不透明度（≈0.06）、出血定位的装饰性文字。
**场景**：封面、章节页的情绪渲染。
**门槛**：纯装饰——【硬规则】必须标 `data-editable-skip`。

### Highlight 荧光标记

**骨架**：正文内对 1–3 个关键词加主题色高亮（`.accent` 色块衬底或下划线）。
**场景**：长句中锚定关键词。
**门槛**：每页 ≤3 处；高亮泛滥等于没有高亮。

## 9. 图片型信息图的 text_policy

需要更复杂的图示（地图、架构图、场景插画）时，生成 SVG/图片放进 `assets/`：

- **图内不嵌文字**（text_policy: none）——文字全部用图外的 HTML 标注承载，保证可编辑；
- 图整体标 `data-editable-image`；
- 这条是契约级约束：图内嵌字 = 那部分文字永远无法就地编辑。

## 11. 构图谱系（六谱系，v3 新增 · 高级感要素 8）

谱系是**页面构图层**：决定整页的骨架与视觉张力来源，在 §0 三步选型之前发生。结构族是信息图的骨架，谱系是页面的骨架——一页 = 一个谱系，谱系内可承载一个信息图主体（§5 一页一个信息图主体不变）。归藏 22 个登记版式可归并为这 6 谱系（证据：`source/guizang-ppt-skill/references/layouts-swiss.md`）。

| 谱系 | 构图描述 | 视觉张力来源 | 亲和结构族（映射参考，非白名单） | 归藏版式证据 |
|---|---|---|---|---|
| `宣言` 巨字宣言 | 巨幅标题（双约束限高 `min(Xvw,Yvh)`）占据视觉中心，辅助信息压到边缘带 | **尺度对比**——字级落差 ≥8:1，大字即图形 | 不承载信息图；配 Callout / Ghost | P1 / P3 / P10 |
| `数据英雄` | 一个（或一组）巨数是主角，其余元素让位成注释层 | **字号差 + 不等高几何**——数字高度/面积承担数据墨迹 | `list`×`stat`、`chart` 族 | P6 / P18 / P20 / P21 |
| `网格矩阵` | 2×N / 3×N 等分网格，单元同构重复 | **秩序 + 单焦点破序**——秩序由网格建立，张力由唯一破序单元（accent 档容器）点燃 | `list/grid`、`compare/quadrant` | P4 / P15 / P16 / P19 |
| `轴与节点` | 一条主轴（横/纵/环）贯穿，节点压轴落位 | **线的引导**——视线沿线行走，连接件的粗细虚实分档承担语义 | `sequence/*`、`relation/*`、`hierarchy/concentric` | P2 / P11 / P14 / P17 |
| `图文证据` | 满幅或大幅证据块（图/截图/标本图）+ 标注层环绕 | **满幅 vs 网格**——证据满幅出血，标注与文字守网格 | 信息图退为配角（标注修饰件）；图走 `assets/` 槽位契约 | P22 / P23 / P24 |
| `裂屏对开` | 页面切为两个（或明暗两块）对峙区域，中缝 hairline | **色彩对撞**——纸/墨或纸/accent 两块明度对撞，中缝是唯一的线 | `compare/binary-cols`、`compare/vs-overlay` | P8 / P9 / P12 |

**节奏纪律（可检查规则）**：

1. 【硬规则】**同一 deck 内禁止连续 3 页使用同一谱系**；7 页以上的 deck 至少使用 3 个不同谱系。检查方式：生成侧在规划清单中逐页标注谱系（`页码 → 谱系 → 选它的理由`，同归藏"页码 → data-layout"纪律），交付说明中列出；连续 3 页同谱系即违规。
2. 谱系 ≠ 内容关系：内容关系仍由 §0 自证清单决定族；谱系只决定页面构图。内容没有图示价值时，文字排版本身就是版式（宣言/裂屏常常不含任何信息图）。
3. 仪式页（封面/章节/封底）几乎总是宣言或裂屏谱系；正文页在其余谱系间轮换。
4. 同一谱系复用时应换构图变体（重心左右互换 / 主轴横纵互换），避免"同谱系同重心"的连续重复。

## 12. 容器规格（四档明度 · 直角纯色 · 单焦点，v3 新增 · 高级感要素 5）

card 皮肤与一切底色块容器（Callout 底、标注旗标底、KPI 塔身等）遵守统一的容器规格。归藏证据：`layouts-swiss.md` 的卡片填充规则（`.card-ink`/`.card-accent`/`.card-fill`/`.card-outlined` 互斥表）。

**四档明度**（一档 = 一种填充立场，互斥不混用）：

| 档 | 填充 | 文字色 | 用途 |
|---|---|---|---|
| 纸档 | 无填充（`var(--paper)` 页面底色），至多 1px hairline 描边 | `var(--ink)` | 默认中性、锚点框 |
| 灰档 | `var(--paper-tint)` 平涂 | `var(--ink)` | 多卡并列的默认容器 |
| 墨档 | `var(--ink)` 平涂 | `var(--paper)` | 反转 / 宣言块 / 破序重音（与 accent 档二选一） |
| accent 档 | `var(--accent)` 平涂 | `var(--accent-on)` | **唯一焦点** |

**硬规则**：

1. **单焦点**：同页一组并列容器里，accent 档**至多一个**；墨档与 accent 档不在同组并列容器中共存（两个重音 = 没有重音）。accent 档面积计入主题 G1 的 accent 用量预算（内容页 ≤10%，themes.md）——容器规格是 accent 预算在组件层的落点。
2. **容器造型语言委托主题（G 期改写）**：容器的圆角/阴影/描边/造型语言（直角纯色块、圆角弥散、描边终端窗、图鉴细描边卡、无框辉光托底……）一律以主题 G4「容器造型」+ G9 母题声明为准，生成侧不自由发挥；本节只管明度档、单焦点、填充互斥与低对比纪律。主题未声明 G4 时走 themes.md 缺省推导（A/B 系直角无阴影，C/D 系 ≤8px）。
3. **填充与描边默认互斥**：填色容器不再加描边、描边只出现在纸档——**例外（K 期深化，demo1 证据）**：暗底主题（paper 为深色）的灰档/墨档容器允许叠加 1px hairline 描边——暗底上面与底明度差小，需要框补边界；亮底主题维持互斥（纸白上灰档面边界自足）。
4. **灰底低对比纪律**：灰档与纸白的对比本来就低——"靠空气不靠边界"：灰档容器之间用间距分区，不再加 hairline 描边、不再压暗底色；需要边界感的容器应升档（墨/accent）或降档（纸 + hairline），不给灰档补边。
5. 容器本体标 `data-editable-skip` 或不标（容器本来就不标 `data-editable`，见契约"标记在最小语义容器上"）；容器内文字照常 `data-editable`——容器规格不改变契约分层。

## 13. 文本容器层（K 期新增 · 高密度页面的层次来源）

结构族管**内容关系**（§0–§10），构图谱系管**页面构图**（§11），明度档管**容器填充纪律**（§12）——本节管最后一层：**文本容器的结构分型**。高密度页面（阅读主导档）的内容大量落在文本容器而非信息图上；容器不分型，层次就退化为"带边框文本块"。

**六型容器**（与结构族正交：族管关系，容器管包装；同一族的内容可装入不同容器型）：

| 型 | 结构 | 适用内容 | 容量 |
|---|---|---|---|
| **字段行 kv-rows** | label/value 两端对齐行 + hairline 行间分隔 | 元信息、规格表、系统状态 | 每容器 4–8 行 |
| **数据带 ticker** | 等宽多格；格内 序号+变化标签 → 大数字 flow（from→to）→ 描述 | 反差数据、KPI 对比 | 2–4 格，至多一排 |
| **指标卡 metric-card** | 编号/图标 + 标题 + 描述 + 可选指标条（mend-bar/fill-bar） | 问题/特性/风险枚举 | 3–5 卡一排 |
| **对照列 versus-cols** | 两列头（可异色异底）+ 逐行对照项 | 二元对比的数据级呈现（裂屏对开是叙事级，本节是数据级，互补不替代） | 每列 3–6 项 |
| **堆栈层 stack-rows** | 全宽横层：层号/名称 → 内容清单 → 右侧注记 | 架构分层、流程分带、权限分级 | 3–5 层 |
| **注记块 note-block** | 小字注 + 引线/左边线（与图表标注层同源） | 脚注、来源、例外说明 | 1–3 行 |

**容器内层次纪律【硬规则】**：容器内层级固定为四层字阶——① eyebrow/tag（mono 小字、低明度）→ ② 题（标题档）→ ③ 体（正文）→ ④ 注（mono 小字注记、低明度）。**相邻两层至少在字号/字重/明度中分化一项；①④两层强制低明度 mono**。容器内全部同字重同明度即违规——层次感是纪律不是灵感。

**与主题的接口**：容器造型（圆角/描边/双线图框/撕线/辉光托底……）一律委托主题 G4「容器造型」与 G9 母题（§12 硬规则 2 同口径）；本节只管结构分型与层次纪律。母题件可作容器的 eyebrow/tag 呈现（如 c4 题花作注记块标头、e2 图框标题栏 `.mt-bp-tag` 作 kv-rows 的标签位、e11 票根字段行即 kv-rows 的主题化形态）。

**密度联动**：高密度档每页可由 1–2 个容器组合承载（如 数据带 + 指标卡排）；低密度档优先用构图谱系的大张力形态，容器型退居配角。ticker/versus-cols/stack-rows 的排间分隔用 hairline 或明度差（主题 G4 口径），不加额外边框墙。

**密而不乱纪律**（K 期深化，证据 `docs/research/demo1-density-analysis.md`）【硬规则】：

- **密度目标**：高密度内容页 3–5 个容器区/页、每容器 4–6 信息件（tag/题/体/注/指标条）；文本叶 ≥55 个/页（demo1 实测口径）；
- **主次靠明度分层，不靠留白分层**：标注层全部退到 40–65% 明度形成"印刷肌理"，页面焦点仍只有 1–2 个（巨字 + accent 单焦点）；容器内部不留大负空间——负空间在容器之间；
- **同构重复**：同一页内同型容器的内部结构必须同构（同一套四层字阶），视觉秩序来自重复的结构而非减少的信息；
- **容器边界义务【硬规则】**：高密度页的每个容器区必须有明确边界手段——**面（明度档填充）或框（描边/角括号 `.rl-corners`）其一**；"裸排 + 仅线分隔"只够低密度档。密而不乱的秩序源：同页容器同构——同 gap、同 padding、同边界手段（demo1 实测：面占面积 25–50%、gap 恒定 20px、padding 恒定，秩序来自边距系统的恒等而非内容减少）；
- **隔离三手段选型**：面（填充，暗底/卡片阵主力）/ 框（描边，亮底报纸与图纸世界的"栏框"）/ 线（分隔，最轻量）。每页一个主力手段 + 线做层级内细分，禁止同页混用面与框（视觉体系分裂）；主题 G4 容器造型决定选哪个，但高密度档不允许"只有线"。

## 14. 装饰线与装饰元素（通用语法层 · v7.2 / K 期深化）

**分层关系**：本节是**通用语法**（线的种类与用法纪律，全主题共享的"字母表"）；主题 G9 母题是**专属词汇**（线在这个主题里长成什么样）；主题 G4 的 hairline 策略管颜色/粗细/明度。语法共享不回退到装饰趋同——差异化由词汇层承担（b1 的加号、e8 的粗细双线、e2 的延伸线都是同一语法在不同世界的词汇）。

**装饰线五款**（骨架 `.rl-*`，全部装饰件、产物标 `data-editable-skip`）：

| 类 | 线型 | 适用 | 禁忌 |
|---|---|---|---|
| `.rl-dashed` | 虚线分隔 | 松散分区、票据/手账气质 | 与图表虚线（投影线/参考线）同页撞车时改实线 |
| `.rl-ticks` | 刻度尺线 | 度量语境（数据页页缘、时间轴底轨） | 非度量语境禁用（无对象的刻度是噪音） |
| `.rl-leader` | 引线点线（flex 行内：左标签 …… 右值） | 目录、清单的对位引导 | 每页至多一组（目录/清单区） |
| `.rl-fade` | 渐隐线（向一端消隐） | 页面收束、区块软分隔 | 双向渐隐禁用（两头消隐即无方向） |
| `.rl-corners` | 角括号（容器对角直角标） | 容器/图位的"取景框"强调 | 一容器只许对角两枚；与描边框不同时用 |

**装饰元素三族**（无类、生成侧按纪律落码）：

- **几何小件**：方块/圆点/三角/菱形（实心或描边，8–16px）——列表符号、状态点、分隔点；accent 材质计入预算；
- **符号字符**：❧ ◆ ● ▪ → ↳ № § ¶ 等 Unicode——题花、注记、序号前缀；每页至多一族符号，不混族；
- **纹样带**：repeating 纹样横带（页缘装饰带）——属主题 G9 母题词汇（如 e7 浪花带、e11 齿孔带），不通用化。

**纪律【硬规则】**：每页装饰线 ≤3 款；装饰元素必须服务结构（分隔/引导/标记/取景），无对象的空装饰禁止；装饰件全部 `data-editable-skip`；装饰线颜色明度服从主题 G4 hairline 口径（通用语法不自带颜色主张）。
