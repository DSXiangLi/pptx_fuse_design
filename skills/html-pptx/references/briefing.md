# 需求脑暴（Briefing）：制作前的需求对齐清单

> 对应 SKILL.md Step 0.5。原则：脑暴是**对齐不是问卷**——目的是在写第一行代码前冻结决策（第一性原则 1 的前移）。每组问题给默认缺省，用户没答就走缺省不追问；全部问题至多两轮交互。
> 编辑器侧的实现（需求脑暴页）与本文档共享同一份问题模型与简报格式——editor.html 的脑暴页是本文档的 UI 形态。

## 问题组（八组 + 自由补充）

**① 使用场景**（单选）——决定密度与动效的默认锚点：
- 现场演讲（keynote）→ 缺省：低密度 + 标准动效 + 明暗节奏强
- 阅读分发（报告/文档）→ 缺省：高密度 + 克制动效
- 汇报答辩（限时讲完）→ 缺省：低密度 + 标准动效 + 页数经济
- 大屏/展台循环 → 缺省：低密度 + 华丽动效 + 高对比
- 网页嵌入/分享链接 → 缺省：高密度 + 标准动效

**② 受众**（单选）：技术同行（缺省） / 管理层 / 大众科普 / 客户或甲方——影响语言深度与「呈现发散」的隐喻选型（管理层偏结论先行 + 数据英雄页；技术受众可上架构堆栈与终端系主题）。

**③ 内容来源与切分**（单选 + 追问）：
- 从 0 到 1（主题/资料）→ 追问：叙事弧偏好——问题-方案-证据 / 时间线演进 / 总-分-总 / 对比论证（缺省：从内容里长出来，不套模板）；
- 现成 pptx 转换 → 走 SKILL.md Step 0 转换通道（内容重组非逐页复刻）；
- 已有大纲/文稿 → 直接进页计划表。

**④ 页数/时长预算**（单选）：≤8 页 / 8–15 页（缺省） / 15–25 页 / 不限——与密度档联动校验：高密度 + ≤8 页且内容多 → 提示加页或升密度。

**⑤ 视觉风格**（主题卡单选 + 变体）——来自 themes.md 的 20 重主题 × 变体；问法不是"选哪个主题"而是"这份内容应该是什么气质"，给 2–3 个推荐 + 全库自选。**品牌色适配纪律**：用户报品牌 VI 色时，不自定义 hex（禁忌不变）——选色距最近的变体并在简报中声明映射（"品牌红 #X → e8 号外红变体"）。
- **风格合理性回谏**：若用户指定风格与内容/场景明显不匹配（如合规报告选 Memphis 糖果风），agent 必须提出异议并给替代建议——回谏一次，用户坚持则从之并记录在简报。

**⑥ 字体偏好**（单选）：系统栈默认（离线，缺省）/ 接受联网字体（解锁主题 G2「display 联网备选」）/ 指定气质（衬线人文 / 黑体现代 / 手写温度——映射到主题 L2 层差异）。

**⑦ 动效与明暗**（各单选）：动效 克制/标准/华丽（五层矩阵语义不变）；明暗 亮底/暗底/混合节奏（缺省按主题世界决定）。

**⑧ 封面与交付**（多选 + 补充）：封面元素——主标题/副题/日期/演讲人/品牌位/章节目录（高密度档目录默认必载）；插画模式——纯 HTML（缺省）/ AI 插画（Step 5.5 管线）；尺寸——当前交付形态固定 16:9 网页版（声明项，不是选项）。

**自由补充**：任何不在上面的要求（口头禅、禁忌、参考物）。

## 简报输出格式（agent 与编辑器共用）

```
需求简报 · <一句话主题>
场景：<①> ｜ 受众：<②> ｜ 页数预算：<④>
内容来源：<③ 含叙事弧>
密度：<低密度/高密度> ｜ 动效：<档> ｜ 明暗：<…>
主题：<id + 变体>（品牌色映射：<如有>）
字体：<⑥> ｜ 插画：<⑧>
封面元素：<⑧ 多选>
自由补充：<如有>
风格回谏记录：<如有>
```

## 纪律

- 缺省驱动：每组都有缺省，用户答几组算几组，缺省项在简报里标注（缺省）；
- 追问上限两轮：第一轮呈现问题组（编辑器脑暴页 = 一轮收敛），第二轮只追问矛盾项（如"阅读分发 + 华丽动效"需确认）；
- 脑暴结果冻结后进入 Step 1 页计划表——页计划表的密度/主题/动效档必须与简报一致，不一致处要在页计划表里说明谁改了谁。
