# 字排与容量规范（Typography & Capacity）

> 本文件把"容量先于版式"原则操作化：先量内容，再定字号与构图。
> 所有数值以 **1920×1080 画布坐标系 px** 为准（由 guizang 的 vw/vh 表换算：1vw=19.2px，1vh=10.8px）。

## 1. 中文大标题分档

中文是方块字，不能套英文 hero 的字号直觉。按**标题行数与单行字数**分档：

| 标题形态 | 字号 | 说明 |
|---|---|---|
| 封面/收束金句，≤6 字 | 144–160px | 仅 hero 页可用的特档，一页一个 |
| 1 行，≤8 字 | 120px | 内容页主标题最有冲击力的档，优先争取 |
| 2 行，每行 ≤8 字 | 110px | |
| 2 行，含 9–12 字的行 | 100px | |
| 3 行及以上 | **先改写标题** | 不得已才用 88px；标题长是写作问题不是排版问题 |

## 2. 字号下限（硬规则）

| 角色 | 下限 |
|---|---|
| 正文 | 18px |
| 图注 / 卡片描述 | 16px |
| meta / kicker / 图表标签 | 14px |
| **标注层**（K 期新增，见 §5 标注层条款） | 12px——仅高密度档、且满足标注层纪律才合法 |

装不下的处理阶梯：微调间距 → 精简文案 → 拆页。**禁止**用 14px 以下的字号硬塞**正文/描述/meta**（标注层是唯一例外，且是"印刷肌理"不是塞字手段）。

## 3. 字重映射表（越大越细）【硬规则】

无衬线 display 的主题（B 系及一切走"倒挂阶梯"的主题）照归藏口径逐档映射，禁止凭感觉取字重（vw 为画布坐标系换算锚点，1vw=19.2px）：

| 字号 | 对应 vw | 字重 | 典型场景 |
|---|---|---|---|
| ≥154px | ≥8vw | 200 | 封面巨字、巨号 KPI、宣言页 |
| 77–153px | 4–7.9vw | 200–300 | 章节标题、大编号 |
| 35–76px | 1.8–3.9vw | 300–400 | 内容页主标题、takeaway、中号数字 |
| 17–34px | ≈正文带 | 400–500 | 正文段落、卡片描述 |
| 14–16px | 小字带 | 500–600 | meta、kicker、角标、图表标签 |

配套硬规则：

- **同页倒挂**：同页内小字的字重 ≥ 大字的字重（不允许 16px 正文用 300 而标题用 500——视觉灰度会塌）；
- **小字可读性下限**：14–18px 小字禁用 300（太细不可读），最低 400、推荐 500；
- **例外立场（主题级声明）**：衬线 display 主题（A 系 / C4 / D2 / D3）细字重在大字号下发虚，不走倒挂，display 恒重 500–700、靠字号差建层级；C1 信号黑反向对比（标题极粗 800–900）是其主题立场。例外必须写在主题的 G2 字重映射里，不允许临时发明第三种立场。

## 4. 槽位字数预算

每个文字槽位按角色有物理预算。**计数按视觉宽度折算：全角字符（CJK）记 1，半角记 0.5**。

| 槽位角色 | 预算 | 典型元素 |
|---|---|---|
| display（标题/金句） | ≤36 | h1/h2 |
| brief（摘要/导语） | ≤80 | lede、副标题 |
| body（正文段落） | ≤120 | p、li 单条 |
| compact（标签/小标题） | ≤20 | kicker、tag、卡片标题 |
| metric（大数字含单位） | ≤16 | stat 数字 |

超预算 = 内容规划错了：精简或拆页，不缩字号。

## 5. 密度双档（开工前冻结的决策）

只有两档，不发明中间档；内容混合时**向更近的一档靠拢**：

| | 低密度（演讲主导） | 高密度（阅读主导） |
|---|---|---|
| 单页信息量 | 一页一意，1–3 个要点 | 自包含，4–8 个要点或 4–6 个卡片 |
| 字号对比【硬规则】 | 主标题:正文 **≥8:1**（如 144px:18px）——巨字双约束限高 `min(Xvw, Yvh)` | 主标题:正文 **≥5:1**——高密度信息承载优先，不硬套 8:1，但对比低于 5:1 即层级塌陷 |
| 版式 | 大量留白，构图极简 | 结构化 grid / 表格 / 注释，间距收紧但有意 |
| 页数策略 | 宁可加页 | 页数经济，但共享同一底线 |

两档共享底线：不溢出、不缩字号、超出容量就拆页（竖向滚动形态下加页是免费的）。

**高密度档的容器化义务**【硬规则】（K 期）：高密度页的要点必须装进 components.md §13 的文本容器分型（字段行/数据带/指标卡/对照列/堆栈层/注记块），并遵守容器内四层字阶纪律（① eyebrow mono 低明度 → ② 题 → ③ 体 → ④ 注 mono 低明度；相邻两层至少在字号/字重/明度中分化一项）。高密度页"裸排正文列表"即违规——层次感由容器结构承担，不由字号大小承担。

**标注层（K 期深化，demo1 解剖证据 `docs/research/demo1-density-analysis.md`）**：高密度档是**双层制**——正文层（≥18px）+ 标注层（12–16px）。标注层是印刷级密度的来源（demo1 每屏 21–54 个微字标注，没有它的 deck 字符量少一半）：

- 标注层五纪律【硬规则】：mono 字体 + 低明度（40–65%，color-mix 派生）+ 短文本（≤20 字符）+ 拉丁大写宽字距（中文标注不加字距）+ 不承载关键结论（关键数字永远不在标注层）；
- 配额：每容器 2–4 处标注（标签/单位/序号/来源/状态），内容页标注层文本 ≥15 处——标注层不是点缀，是高密度档的默认肌理；
- 字阶频谱连续：高密度页字号档 ≥8 档，从巨字到标注层中间不断档（巨字/标题/小标/正文/标注五区连续覆盖）；
- 低密度档不用标注层（留白叙事不需要印刷肌理）。

## 6. 行高

中文行高比西文宽：标题 ≥1.3，正文 ≥1.6。中文不设 `letter-spacing`，不用 `text-transform: uppercase`。

## 6.5 容器余量纪律（三形态 M3 防线 D）

导出管线的版式真相烙入转换机的浏览器：本机缺主题字体 → 回退字体度量不同 → 换行漂移。防线 A/B/C 分别消灭变量、有界缓释、测量阻断；本节是生成侧的结构韧性——**让微小度量差不破版**：

- 【默认】文本容器的内容高度 ≤ 容器高度的 **85%**，剩余 15% 是排版余量，不是"没用满"；
- 【默认】行高取档时多留半行 slack：按预算行数 +0.5 行的高度估算容器，卡线排布的容器（内容高度 >95%）本身就是溢出预备役；
- 余量纪律不替代容量预算（§4）：先数对字数，再留余量；靠余量硬塞超预算内容是本末倒置。

## 7. 文字呈现与效果（skeleton v7.2 / K 期深化，证据 docs/research/demo1-density-analysis.md §五/§六）

"字体呈现"不是选一款字体——它有五个独立的表达轴。选型时逐轴过一遍，而不是只盯字体栈：

| 轴 | 空间 | 落法 |
|---|---|---|
| ① 字内填充 | 实色（默认）/ 描边 / 渐变 / 错版叠印 / 发光 | `.tt-outline` / gradient-flow（动效款）/ `.tt-shadow` / `.tt-glow` |
| ② 字外装饰 | 荧光标记 / 粗下划线 / 删除线 / 题花注记 | `.tt-mark` / `.tt-uline` / `.tt-strike` / 主题 G9 |
| ③ 排印方向 | 横排 / 竖排 / 微斜排 / 基线错位 | `writing-mode:vertical-rl`（a1/e7 母题先例）/ rotate ≤3° / 逐字 transform 交错 |
| ④ 尺度形态 | 巨字 / 窄体拉伸 / 大小混排 | 字号对比档（§1/§5）/ `.tt-cond` / 首字下沉（c4 母题先例） |
| ⑤ 字重混排 | 恒重 / 倒挂 / 同句跳跃 | 主题 G2 字重映射；同句 300+900 混排是张力来源（大留白页限定） |

**骨架 `.tt-*` 词汇表**（纯 CSS、离线无害、文字保持纯文本可编辑；主题在 G2「标题修饰」声明亲和/禁忌）：

| 类 | 效果 | CSS 落法 | 适用 | 禁忌 |
|---|---|---|---|---|
| `.tt-outline` | 描边字（透明填充 + 描边） | `-webkit-text-stroke:1.5px var(--tt-c)`，`--tt-c` 默认 ink，可设 accent | 大字号标题/大数字（≥64px，小了描边糊）；与填充词**混排**是签名手法（demo：SMART 填充 + CONTENT 描边） | 正文禁用；每页至多一处；编辑态还原本色（契约 v6.4） |
| `.tt-strike` | 加粗删除线 | `line-through` `.07em` | 反差数据带的 from 值（¥2,000→¥0 的 ¥2,000）、被否定的旧方案 | 禁用于正文句子；只删"被取代物" |
| `.tt-mark` | 荧光笔标记 | accent 45% 底纹下 62% | 关键词、结论句中的记忆点 | 每段至多一处；accent 预算计入 |
| `.tt-uline` | 粗下划线 | `inset 0 -.12em` accent 条 | 标题内 accent 关键词（demo 的 em 下划线） | 与链接样式混淆处禁用 |
| `.tt-shadow` | 错版叠印（双色阴影错位，印刷套不准美学） | `text-shadow: .05em .05em 0 var(--tt-c)`（accent 影 + ink 字） | display 标题/大数字；e1 孔版/e8 报纸亲和 | 小字禁用（<32px 糊）；暗底主题慎用（叠印发脏） |
| `.tt-glow` | 发光字 | `text-shadow: 0 0 .4em color-mix(accent 55%)` | 暗色主题的标题/关键数字；c1/c2/d2/e10 亲和 | 亮底禁用（光无从谈起）；每页至多一处；正文禁用 |
| `.tt-cond` | 窄体拉伸（穷人版 condensed） | `transform: scaleY(1.22)`，inline-block 化 | display 巨字模拟窄体性格（离线替代联网窄体） | 【transform 互斥】与 data-anim 位移类/data-ptr/data-scroll 不同元素；正文禁用 |

**混排手法**（词汇之外的组合技）：同一标题内"填充词 + 描边词"混排（如 SMART FORGE 填充 / PIPELINE 描边）——accent 预算内，描边词充当"背景层文字"，填充词是焦点；祭献一个词给氛围，成就另一个词的记忆点。

**display 字体的联网备选**（G2 可选字段「display 联网备选」）：系统栈是第一公民（离线可用方针不变）；主题可声明一个性格 display 字体的联网备选（如 c1→Bebas Neue 类窄体），写法 = 字体名 + fallback 栈 + 加载条件——**仅当用户明确接受联网加载时**由生成侧注入 `<link>`，fallback 栈必须与系统栈气质同构（窄体/几何/书法等），离线时回落无感。
