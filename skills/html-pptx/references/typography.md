# 字排与容量规范（Typography & Capacity）

> 本文件把"容量先于版式"原则操作化：先量内容，再定字号与构图。
> 所有数值以 **1920×1080 画布坐标系 px** 为准（由 guizang 的 vw/vh 表换算：1vw=19.2px，1vh=10.8px）。

## 1. 中文大标题分档

中文是方块字，不能套英文 hero 的字号直觉。按**标题行数与单行字数**分档：

| 标题形态 | 字号 | 说明 |
|---|---|---|
| 封面/收束金句，≤6 字 | 144–160px | 仅 hero 页可用的特档，一页一个 |
| 1 行，≤8 字 | 120px | 内容页主标题最有冲击力的档，优先争取 |
| 2 行，每行 ≤8 字 | 110px | |
| 2 行，含 9–12 字的行 | 100px | |
| 3 行及以上 | **先改写标题** | 不得已才用 88px；标题长是写作问题不是排版问题 |

## 2. 字号下限（硬规则）

| 角色 | 下限 |
|---|---|
| 正文 | 18px |
| 图注 / 卡片描述 | 16px |
| meta / kicker / 图表标签 | 14px |

装不下的处理阶梯：微调间距 → 精简文案 → 拆页。**禁止**用 14px 以下的字号硬塞。

## 3. 字重映射表（越大越细）【硬规则】

无衬线 display 的主题（B 系及一切走"倒挂阶梯"的主题）照归藏口径逐档映射，禁止凭感觉取字重（vw 为画布坐标系换算锚点，1vw=19.2px）：

| 字号 | 对应 vw | 字重 | 典型场景 |
|---|---|---|---|
| ≥154px | ≥8vw | 200 | 封面巨字、巨号 KPI、宣言页 |
| 77–153px | 4–7.9vw | 200–300 | 章节标题、大编号 |
| 35–76px | 1.8–3.9vw | 300–400 | 内容页主标题、takeaway、中号数字 |
| 17–34px | ≈正文带 | 400–500 | 正文段落、卡片描述 |
| 14–16px | 小字带 | 500–600 | meta、kicker、角标、图表标签 |

配套硬规则：

- **同页倒挂**：同页内小字的字重 ≥ 大字的字重（不允许 16px 正文用 300 而标题用 500——视觉灰度会塌）；
- **小字可读性下限**：14–18px 小字禁用 300（太细不可读），最低 400、推荐 500；
- **例外立场（主题级声明）**：衬线 display 主题（A 系 / C4 / D2 / D3）细字重在大字号下发虚，不走倒挂，display 恒重 500–700、靠字号差建层级；C1 信号黑反向对比（标题极粗 800–900）是其主题立场。例外必须写在主题的 G2 字重映射里，不允许临时发明第三种立场。

## 4. 槽位字数预算

每个文字槽位按角色有物理预算。**计数按视觉宽度折算：全角字符（CJK）记 1，半角记 0.5**。

| 槽位角色 | 预算 | 典型元素 |
|---|---|---|
| display（标题/金句） | ≤36 | h1/h2 |
| brief（摘要/导语） | ≤80 | lede、副标题 |
| body（正文段落） | ≤120 | p、li 单条 |
| compact（标签/小标题） | ≤20 | kicker、tag、卡片标题 |
| metric（大数字含单位） | ≤16 | stat 数字 |

超预算 = 内容规划错了：精简或拆页，不缩字号。

## 5. 密度双档（开工前冻结的决策）

只有两档，不发明中间档；内容混合时**向更近的一档靠拢**：

| | 低密度（演讲主导） | 高密度（阅读主导） |
|---|---|---|
| 单页信息量 | 一页一意，1–3 个要点 | 自包含，4–8 个要点或 4–6 个卡片 |
| 字号对比【硬规则】 | 主标题:正文 **≥8:1**（如 144px:18px）——巨字双约束限高 `min(Xvw, Yvh)` | 主标题:正文 **≥5:1**——高密度信息承载优先，不硬套 8:1，但对比低于 5:1 即层级塌陷 |
| 版式 | 大量留白，构图极简 | 结构化 grid / 表格 / 注释，间距收紧但有意 |
| 页数策略 | 宁可加页 | 页数经济，但共享同一底线 |

两档共享底线：不溢出、不缩字号、超出容量就拆页（竖向滚动形态下加页是免费的）。

## 6. 行高

中文行高比西文宽：标题 ≥1.3，正文 ≥1.6。中文不设 `letter-spacing`，不用 `text-transform: uppercase`。
