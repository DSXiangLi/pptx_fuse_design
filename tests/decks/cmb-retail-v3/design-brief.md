## 主题冻结（deck 级定制）

**彩色新粗野**：奶油纸底 + 墨黑粗描边 + 策展五色 + 硬偏移投影。新粗野是"多彩即本体"的语言，但商务驯化纪律：五色是策展色板不是随机糖果色；粗描边与硬投影承担结构职能，不撒装饰。

- token 已注入骨架 `:root`（SLOT: theme tokens），落码一律 `var(--*)` / `color-mix()`，**禁字面 hex**。
- **五色章节色相系统**【本版核心】：每页 section 带 `data-hue="c0..c5"`，CSS 按档覆盖 `--accent`——c0/c1 朱红 #E43D25（封面/目录/封底/第一章）、c2 钴蓝 #2456D6（历史合作）、c3 松绿 #1F9D64（投研能力）、c4 明黄 #F2B100（零售业务，accent-on 反墨）、c5 青碧 #0E8F8A（未来规划）。页内一切 `var(--accent)` 派生（标题荧光、焦点块、图表系列色）自动随章换色；封面/封底五色并置。
- G3 质感：flat 立场——新粗野是平涂世界，纸纹颗粒都不要。
- 字重立场反转【与 v2 的核心差异】：新粗野的大字是 800 极粗（标题/大数字 200/300→800 全局提升），小字维持 400–600。字重差本身即装饰。

### 禁用的 E4 词汇（串味即失败）
禁 `.mt-bau-*` 基本形三件套（正圆/三角/方块低透明构成）、禁 2px 细结构线（新粗野结构线 = 3px 墨线）、禁字重倒挂。

### v3 母题词汇（.mt-nb-*，母题件一律 data-editable-skip）
1. **`.mt-nb-ring`** 描边圆环——3px 墨描边空心圆，背景构成件（替代 v2 低透明实心圆）。
2. **`.mt-nb-disc`** 实心圆盘——3px 墨描边 + 8px 墨硬偏移投影，填色由 inline background 给（accent/paper/ink）。
3. **`.mt-nb-block`** 色块——3px 墨描边 + 8px 硬投影的矩块；墨填色变体 `.mt-nb-block-ink`（投影换 accent 防糊）。
4. **`.mt-nb-star`** 爆炸星——clip-path 十二角星，只许仪式页焦点位（封面/封底/章节页），正文页禁用。
5. **`.mt-nb-line`** 3px 墨结构线（替代 v2 的 2px）。
6. **`.mt-nb-chip`** 贴纸标签——2.5px 墨描边 + accent 底 + accent-on 字 + 5px 硬投影，inline-block；承载真实文字时文本照常 data-editable。

纪律：每页母题件 1–3 件；硬投影一律 var(--ink)（ink 填色件除外）；正文字号/字阶/容器字阶纪律与 v2 相同（高密度档）。
