# isolation-ab · 内容隔离方式 A/B/C 对照 deck

> 目的：供肉眼验收「内容隔离方式」范式修正（components.md §12 暗底面+框叠加例外 + §13 容器边界义务）。
> 背景：demo1 解剖发现高密度页面的内容隔离 = **面（底色填充）+ 框（1px 描边）+ 线（分隔）+ 空（恒定 gap/padding）** 的组合；既有 deck 的缺陷是只有线（e8 报纸版 0 面）或面弱无框（c1）。

## 控制变量

三页**完全相同的内容**（SmartForge 痛点页：标题「四大漏洞」+ 4 张漏洞卡 × mend-bar），除卡片容器的隔离手段外一切相同：

- 骨架 v7.2 逐字复制（diff 确认框架层 0 改动，只填 4 个 SLOT：标题 / theme tokens / theme css / slides）；
- 主题 = **C1 信号黑**基底变体 token + G9 母题 css（暗底——覆盖「暗底允许面+细框叠加」例外条款的场景）；
- 同排版（head-row / lede-row / cell-head / lrow / note-block + 刊头家具）、同字阶（12/13/14/15/18/20/28/108 共 8 档正文档）、同 mend-bar 参数（--from:94/86/100/78 → --val:0）、同标题动效（chars 逐字，C1 缓动签名 cubic-bezier(.2,1.25,.3,1)）；
- 卡片 box 几何三页逐像素一致（border-box + 透明边框占位，截图扫描验证：卡边缘 x 坐标三页同为 120/515/548/943/976/1371/1404/1799）；
- 标注层（mono 12–13px 低明度）三页等量落地（每页 anno=23）。

## 三版差异点（唯一变量：.lcard 的容器边界）

| | 页 A「线隔离」 | 页 B「框隔离」 | 页 C「面+框」 |
|---|---|---|---|
| 隔离手段 | 卡间 1px hairline（ink 26%）×3 + 裸排 | 每卡 1px 描边框（ink 30%），无填充 | --paper-tint(#242424) 灰档面 + 1px hairline 框叠加 |
| 面 | 无 | 无 | 有（demo 式） |
| 框 | 无（透明边框占位保几何） | 有 | 有 |
| 线 | 仅分隔线（3 条） | 框即线（8 条边缘） | 框即线（8 条边缘） |
| 空 | 恒定 gap 32 / padding 32×30（三页同构） | 同 | 同 |
| 代表 | 现状（e8 报纸版 0 面同类缺陷） | 中间档 | demo1 式（修正目标） |
| mastfoot 标注 | A · 线隔离（现状） | B · 框隔离 | C · 面+框（demo 式） |

像素验证（y=600 横扫，卡内亮度均值）：A 仅 3 条分隔线、卡内 #1a1a1a；B 8 条边缘线、卡内 #1a1a1a；C 8 条边缘线、卡内 #242424（面生效）。
