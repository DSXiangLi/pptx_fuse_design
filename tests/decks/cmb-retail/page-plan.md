## 主题冻结（Step 2 结论）

**B1 瑞士国际主义（id: b1）· 基底配色（IKB 蓝）**，三个变体（柠檬黄/柠檬绿/安全橙）均不采用。

理由：
- 银行零售高拜汇报 = 金融机构商务场景，要求稳重、可信、专业。B1 是库中气质最保守的一套：高级灰白底 + 单一高饱和蓝 accent + hairline 网格纪律，G5 动效气质 professional，G3 flat 立场（无任何纹理噪声），G8 亲和网格矩阵/数据英雄/裂屏对开——与本 deck 大量表格、KPI、双栏对比内容天然匹配。
- accent #002FA7（IKB 蓝）是金融机构通用的"可信蓝"，比柠檬黄/柠檬绿/安全橙三个变体更符合银行语境；变体均偏年轻/警示向，不采用。
- A 系衬线杂志风偏文化叙事、C 系深色不符合"明暗=亮"、D/E 系（奶油/油彩/孟菲斯/浮世绘等）个性过强，均排除。
- 本 deck 是后续生图与可编辑 pptx 导出的**测试基准**，选最稳的主题降低变量。

## 给分包施工代理的约定（照做，勿自由发挥）

### 版式与类名
1. **骨架零改动**：`index.html` 框架层（两个"框架层 · 禁止修改"注释区间）一字不动；只在 `SLOT: slides` 标记区间内追加页面。新页一律 `<div class="slide-slot"><section class="slide" data-slide-id="…">…</section></div>`。
2. **slide_id**：用语义 kebab-case（本计划表逐页给定），禁用页码式 id。
3. **字阶（高密度档，画布 px）**：页标题 h2 = 56–64px / 字重 300–400；小节号 kicker（如"1.1"）= mono 20px / 500 / 低明度；正文 ≥18px / 400–500；卡片描述 ≥16px；标注层 = mono 12–16px + `color-mix(in srgb, var(--ink) 45%, transparent)` 级低明度 + ≤20 字符 + 不承载关键结论；来源脚注走**注记块 note-block**（mono 14px 低明度，页底部）。字重倒挂：同页小字字重 ≥ 大字字重；14–18px 小字禁 300。**硬检口径**：j_render_check 对非家具文字 <18px 一律判违规，唯一豁免是 mono 字体（meta ≥14px / 标注层 12–13.9px 且低明度）——凡 18px 以下的文字（含容器 eyebrow）必须显式 `font-family:var(--font-mono)`。
4. **容器（K 期 §13，硬义务）**：高密度页的要点必须装进六型容器——字段行 kv-rows / 数据带 ticker / 指标卡 metric-card / 对照列 versus-cols / 堆栈层 stack-rows / 注记块 note-block；裸排列表即违规。容器边界手段本 deck 统一为**面（灰档 `var(--paper-tint)` 平涂）为主力 + hairline 层级细分**（B1 G4 口径：直角色块、无阴影、无圆角；面与框不同页混用）。容器内四层字阶：① eyebrow（mono 低明度）→ ② 题 → ③ 体 → ④ 注（mono 低明度）。
5. **accent 预算**：内容页 accent 面积 ≤10%、单页至多一个 accent 档容器（单焦点）；巨数可用 accent 色一处。墨档与 accent 档不在同组并列容器共存。
6. **母题（只用 B1 G9 词汇）**：`.mt-swatch` 色块编号（章节序号/列表编号，编号文字 data-editable）、`.mt-cross` 加号角标（只许页面四角/内容区角点，每页 ≤4，data-editable-skip）、`.mt-grid-dots` 网格点阵（只许仪式页背景，data-editable-skip）。禁 Ghost 字、禁竖排题字条（那是 A 系词汇）。
7. **装饰线**：`.rl-*` 每页 ≤3 款、一律 data-editable-skip；目录/清单对位用 `.rl-leader`（每页至多一组）。
8. **动效（克制档硬约束）**：只允许 L1 入场——标题/主容器 `data-anim="wipe-clip"` 或 `class="reveal"`（可用 `style="--d:.2s"` 阶梯）；章节页/封面大标题 wipe-clip 优先（B1 G5 锚点偏好）。**禁** chars/words/shatter/count-up/typewriter/scramble/gradient-flow/mask-lines、禁 mend-bar/data-rotate、禁 data-ptr/data-scroll/amb-*/light-*/data-fx。产物中不得出现拆字 span。
9. **节奏纪律**：谱系逐页按计划表执行（已验证无连续 3 页同谱系）；若施工中必须改谱系，同步回本表并复查相邻页。同谱系复用换构图变体（重心左右互换）。
10. **明暗**：全 deck 亮底（无 .dark 页）；仪式页（封面/5 个章节页/封底）加 `cover-page` class，正文页不加、不加 `texture-on`（B1 flat，质感层恒 none）。
11. **图表**：图表诉求页按 `references/charts.md` v2 配方落码（柱/折线/圆环/条形为主）；几何层 SVG 整体 data-editable-skip，标签/数值文字 data-editable；每个图表页至少一种标注（数值直标/参考线/注释旗标）；数据逐字来自计划表与 md，禁编造。系列色从 chart token 推导（themes.md 文末统一推导规则）。
12. **表格**：原 pptx 表格用 HTML `<table>` 承载，单元格文字 `data-editable`（标在 `<td>`/`<th>` 上）；表格容器灰档面 + hairline 行分隔；12 列宽表字号不得低于 18px——装不下就调整列宽分配（1:1 内容不删，版式自由）。

### 刊头家具（全 deck 统一，范例见第 2、3 页）
- **正文页**（非仪式页）：`<header class="masthead">` 左 = 小节号 + 章节名（如 `1.1 · 整体特色及优势`，`style="letter-spacing:0"`），右 = logo `<img src="assets/s02_02.png" width="182" height="68">`（槽位 `masthead-logo-8x3`，全 deck 复用同一槽位名）；`<footer class="mastfoot">` 左 = `天弘基金 · 业务情况汇报`（letter-spacing:0），右 = 页码 `NN / 54`（NN 为原 deck 页码，两位数字）。家具文字均 data-editable。
- **仪式页**（封面/目录/章节页/封底）：不设 masthead；章节页页码放右下角 mono 16px 低明度（范例见第 3 页）。
- 目录页（p2）已含 logo，后续正文页从 p4 起按上述执行。

### 图片槽位约定（契约 v5，硬规则）
- 每张图：`<img data-editable-image data-image-slot="<页语义>-<角色>-<WxH>" data-image-intent="<一句话画面描述>" data-image-state="uploaded" src="assets/<文件名>" width="W" height="H">`，`state` 一律 **uploaded**（用户真图）。
- **三方绑定（容差 5%）**：slot 声明比例 = img width/height 属性比 = 素材固有比。因此**禁止裁剪式 object-fit 改比例**：显示尺寸必须按素材固有宽高比取（object-fit:cover 只在同比例下作保险）。宽/高属性与 style 像素值保持一致。
- 坐标换算：md 中"页面显示 px"是 1280×720 画布坐标，**×1.5** 换算到 1920×1080；换算后若与固有比冲突，以固有比为准微调。
- 原件显示 0×0 的图（原 deck 中隐藏/贴边小图标）：按语义角色给合理尺寸（图标 40–64px 见方，按固有比），intent 写明角色；无语义价值的隐藏装饰图（如 s46_02 的 2×1px）可放入页内作装饰件位或省略——省略时在交付说明中列出（本表已逐页标注取舍建议）。
- 头像/证件照（p27/p31/p35/p37）：**显示高度统一 150px，宽度 = 150 × 固有比**，object-fit:cover；slot 比例按固有比最简化（多数为 2x3，方形为 1x1）。
- 章节页徽记 s03_01 全 deck 复用槽位名 `chapter-emblem-1x1`（p3/p10/p24/p40/p45 同槽位同尺寸 80×80）。

### 契约标记
- data-editable 只标叶子文本元素（h1/h2/p/li/td/span 等），容器不标；元素内部只含纯文本或 `<b>/<i>/<em>/<strong>/<br>`。
- 装饰（色块/分割线/背景图形/图标底）一律 data-editable-skip。
- 信息图根元素标 `data-ig="<族>-<骨架>"` + `data-ig-skin`，数据单元标 `data-ig-item`（契约 v4）。
- 章节页 `.slide` 带 `id` + `data-chapter`（同 data-slide-id 语义）；目录 nav-link `href="#<id>"`。
