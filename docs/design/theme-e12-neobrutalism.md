# E12 商务粗野（Business Neo-Brutalism）主题入库设计

> 状态：待评审 → 评审通过后实施。
> 来源：`tests/decks/cmb-retail-v3/`（彩色新粗野商务驯化版）已经真实 deck 验证——54 页高密度金融汇报，全门禁通过（j_render / capacity 0 违规 / check-images / k_nav），可编辑轨导出 native_text_ratio=1.0、页级降级 0。本文档把该 deck 级定制主题抽象、压缩、回灌为库内第 21 套主题（**商务粗野**——完整粗野的商务驯化版，非街头粗野本体）（范例是矿不是图）。

## 1. 定位与立项依据

**与源 deck 的关系**：cmb-retail-v3 保留 deck 级 data-hue 扩展**不回迁**；库内 E12 是它的蒸馏（单 accent + 变体），v3 作为该主题的验收资产登记在案。

主题库 20 套全部是**单 accent 世界**（G1 accent 预算 ≤10%），没有任何一套以"策展多色 + 粗描边 + 硬投影"为语言。E12 补的空缺：

- **多彩即本体**：新粗野是设计史上少数多彩平涂为正典的语言，回应"色彩更丰富"类需求时不再只有孟菲斯（戏谑向）一个选项；
- **高密度亲和**：粗描边平面卡 + 实墨结构线天然适合数据密集的阅读型 deck（cmb-retail-v3 实证）；
- **导出最友好**：全平涂、零渐变零弥散阴影，可编辑轨烙图压力最小。

## 2. 与最近邻的分化（入库机器门槛：两两七层 diff ≥3）

最近邻 = **E6 孟菲斯**（共享"粗描边 + 硬偏移投影"表象）。实质分化 ≥4 层：

| 层 | E6 孟菲斯 | E12 新粗野 |
|---|---|---|
| L1 色彩 | 糖果粉单罐（#FF3DA5 明度阶梯凑多彩） | 策展五色板，变体即五色（朱红/钴蓝/松绿/明黄/青碧），纸底为奶油 #FFF6E3 |
| L4 母题 | 彩纸屑碎形/之字波浪线/圆角粗描边卡 | 描边圆环/实心圆盘/直角色块/爆炸星/贴纸 chip/3px 结构线 |
| L5 容器 | 8–16px 圆角 + accent 色硬投影 | 直角 0 圆角 + 墨色硬投影 + 2.5px 描边平面卡（投影只给焦点件） |
| L6 动效 | playful：scale-pop 弹跳 + magnetic + 回弹缓动 | professional 短促：wipe-clip/rise-in，禁弹跳回弹 |
| L7 构图 | 网格矩阵卡片阵亲和 | 图文证据（描边照片卡）/数据英雄（巨数+色块引子）亲和 |

## 3. 七层设计（写入 themes.md 的内容）

- **G0**：id e12；世界参考 = Neo-Brutalism 网页运动 × 丝网印刷海报（套色错位、粗墨框、平涂色块）；unforgettable = **纯墨硬偏移投影**——每个色块/照片卡拖着一块没对准的墨影；focus = G1 + G4。
- **G1**：paper #FFF6E3 / paper-tint #F8EAC6 / ink #17140E / ink-tint #2C2517 / accent #E43D25 / accent-on #FFF6E3；accent 预算 ≤10% 不变；**多彩纪律**：单页单 accent 不破，多色感由"变体即五色 + 章节级色相轮转"表达（见 §4）。
- **G2**：几何无衬线系统栈（同 B1 族）；**极粗标题立场**（≥77px→800、35–76px→700、正文 400、14–16px→500–600）；高密度对比 ≥5:1；标题修饰 = `.tt-mark` accent 荧光。
- **G3**：flat 立场（平涂世界，纹理即背叛）。
- **G4**：圆角 0；无 hairline——2px 实墨结构线；阴影唯一形态 = `box-shadow: Npx Npx 0 var(--ink)`（4/5/8/12px 档）；容器两档 = 描边平面卡（2.5px ink 描边无投影）/ 焦点卡（+8px 硬投影）；高密度边界 = 描边卡阵 + 结构线。
- **G5**：professional；时长档 −1；锚点 wipe-clip + rise-in；禁 scale-pop/persp-in/blur-in/magnetic；缓动不覆盖；fx 全禁。
- **G8**：亲和 = 图文证据（描边照片卡带旋转 ≤2°）、数据英雄、网格矩阵（描边卡阵）；禁忌 = 禁圆角容器/弥散阴影/玻璃拟态/渐变。
- **G9**：`.mt-nb-ring` / `.mt-nb-disc` / `.mt-nb-block` / `.mt-nb-block-ink` / `.mt-nb-star`（仅仪式页）/ `.mt-nb-line` / `.mt-nb-chip`（文本载体，文字保持 data-editable）——CSS 块逐字取自 cmb-retail-v3 已验证实现（8 行，≤40 行约束满足，类名全库唯一）。

**Variants（4 套，基底+变体=5 ≥3 门槛）**：钴蓝 #2456D6 / 松绿 #1F9D64 / 明黄 #F2B100（accent-on 反墨）/ 青碧 #0E8F8A，均只覆盖 G1 六色。**4 个而非门槛 3 个的理由**：五色即本主题的色彩叙事本体——章节轮转玩法（§4）的用色全集就是基底+四变体，删任何一个该玩法缺色。

**G7 插画**：走缺省推导（主题色抽象图形）+ 一句风格注记：平涂粗描边色块插画，禁渐变禁柔影。

## 4. 章节多色轮转（deck 级技巧，不进主题特权）

cmb-retail-v3 的五色章节系统由 `.slide[data-hue]{--accent:...}` 覆盖规则实现——这**不符合 G9 css 白名单**（非 :root 非 .mt-*），因此**不进**主题 CSS 块，只在 E12 条目正文以文字记录为"deck 级玩法"：逐章把 --accent 换成变体色，单页单 accent 纪律不变。未来若该玩法推广，再单独立项进骨架/契约。

## 8. 风险与对策

- **与 E6 混淆**：分化声明逐层核验由校验器强制；L5/L6 差异是硬性的（圆角 vs 直角、弹跳 vs 短促）。
- **画廊页码顺延影响 T18**：先读 T18 断言口径再插页；若页码硬编码则同步更新。
- **五色玩法被误读为多彩随意**：条目内明确"单页单 accent 纪律不变，多彩只走章节轮转"。
