# 主题表达力栈与想象层（G/H 期设计）

> 状态：已审核并实施（G/H 期，2026-09-19） · 日期：2026-09-19
> 依据：`handover-theme-differentiation.md`（用户验收 comment + §5.1 七层表达力栈 / §5.2 想象层 / §5.3 灵感来源 / §5.4 路线）+ `../research/v2-effect-diagnosis.md`（趋同根因）+ baoyu-design / html-ppt-skill 补充调研
> 范围：G 期（主题七层表达力栈）+ H 期（隐喻库 + 呈现发散步）。I 期（20 主题建库）与 J 期（同题重制终验）不在本文范围，仅留接口。

## 一、问题重述

三个 v3 deck 内容不同但观感趋同（全部是"归藏杂志风割"）。根因（handover §5.1）：**主题只拥有"色与字"两个维度的主权，装饰语言、容器形态、动效行为、构图引力全是骨架共享默认值**，而我们 F1–F6 的装饰语言恰好全学自归藏。换色换字不换骨。

用户目标：一期至少 20 个鲜明差异化主题 × 每主题 3 套以上配色；枚举不是重点，重点是**新主题的灵感来源与忠实翻译**。

## 二、核心决策

### D1 · 主题定义的改写：七层表达力栈

主题 ≠ 配色方案。主题 = 七层表达力栈，**两个主题在七层里至少 3 层实质分化，才算两个主题**（baoyu"差异轴纪律"的机器可查化）：

| 层 | 内容 | 字段组载体 | 现状 → 动作 |
|---|---|---|---|
| L1 色彩系统 | 3+ 配色变体 | G1 | ✅ → 变体机制（D3） |
| L2 字体性格 | 配对 + 字重性格 + 字号对比度 | G2 | ⚠️ 趋同 → 各主题补真实差异 |
| L3 质感层 | 材质（纸纹/颗粒/扫描线/辉光…） | G3 | ⚠️ token 有装饰语言没跟上 → 与 G9 联动 |
| L4 装饰母题 | 主题自己的装饰词汇（risograph 套色错位、蓝图标注引线、终端 ASCII 框……不是全都用 hairline 和加号） | **新增 G9 motif** | ❌ → 新建（D2） |
| L5 容器风格 | 卡片/面板造型语言（直角/圆角/描边/玻璃/撕边/叠印…） | G4 扩字段 | ❌ → 扩（已有"圆角/阴影委托 G4"先例裂缝：components.md §12 硬规则 2） |
| L6 动效签名 | 主题独有的节奏与 recipe 倾向 | G5 扩字段 | ❌ G5 只有减法（禁用清单）→ 加加法（签名） |
| L7 构图倾向 | 谱系偏好与禁忌 | G8 扩字段 | ❌ → 扩 |

### D2 · 骨架 v6：`SLOT: theme css`（主题 CSS 主权通道）

现状：主题只有 token 值通道（`SLOT: theme tokens`），承载不了需要选择器的装饰母题与容器造型。骨架 v6 在**框架层 CSS 之后、`</style>` 之前**新增第二个主题槽位：

```
/* ===== SLOT: theme css（主题自带 CSS 块）=====
   选定主题后从 themes.md 该主题 G9 的 css 块逐字复制。
   只允许三类规则：① :root{} token 重定义（缓动签名/母题参数）
   ② .mt-* 前缀母题类（命名空间防碰撞） ③ .mt-* 的伪元素装饰。
   颜色只许 var(--*)/color-mix() 引用 token，禁字面 hex；
   禁外部 url()（同 G3 纪律）；禁覆盖框架选择器（.slide/.masthead 等）。
   无母题的主题留空即合法。 */
```

设计要点：

- **位置即能力**：缓动三 token（`--ease-out/--ease-shift/--ease-loop`）在框架层 `:root` 定义、被全框架 `var()` 消费，主题块置后即可用 `:root{}` 重定义——**动效签名的缓动维度零骨架改动获得 CSS 通道**；时长维度走生成侧纪律（G5 节奏偏移声明时长档偏移），不为签名改框架层时长常量。
- **`.mt-*` 命名空间**：母题类一律 `mt-` 前缀，与框架类、产物 inline style 隔离；母题件在产物中带 `data-editable-skip`（装饰不进编辑）。
- **膨胀控制**：母题走"主题自带 CSS 块"（SLOT 注入）而非框架层硬编码；每主题母题 CSS ≤40 行；无母题主题留空零成本。骨架只加槽位注释，不加任何母题实现。
- **兼容性**：槽位是注释界标的空块，旧产物（v3–v5.1 骨架）不含该槽位不受影响、不强制回填；编辑器序列化只动 body DOM，`<style>` 原样保留，编辑器零适配成本；editing-contract 升 v6.2 补保留条款。
- 骨架 meta `skeleton-version` 5.1 → 6。
- **类名全库唯一**：`.mt-*` 类名跨全部主题不得重名（校验器强制）——否则 gallery 样张页（9 主题同文件）与未来的撞脸矩阵页会互相污染。
- **样张页的 `:root` 转写**：主题 CSS 块在真实产物里是文档级 `:root{}`；gallery 样张页 9 主题共存一文件，注入时把 `:root{}` 规则转写为该 section 的 style 属性（token 经内联 var 设置在子树生效，与画廊现有 token 豁免同机制），`.mt-*` 类规则原样进画廊 `<style>`（靠全库唯一防冲突）。此转写只属画廊豁免，产物侧不存在该问题。

### D3 · 两级主题架构：重主题 + 配色变体

html-ppt-skill 的直接教训：36 主题里 15 行纯调色板的那一半，正是没有质感/容器/字排层的下场。配色变体不该稀释主题差异化。架构分两级：

- **重主题**：七层齐备的完整世界（对应 handover"20 个鲜明主题"的计数单位）。
- **配色变体（Variants）**：同一世界的不同"光线/时辰/材质"演绎（蓝图的白线蓝底/蓝线白底/黑板粉笔）。变体 = 名字 + 一句话气质 + G1 六色 token，**可追加 G3 覆盖**（材质演绎合法）；其余五层与基底共享。每主题配色套数 = 基底 + 变体 ≥ 3。

**存量 16 主题诚实重组为 9 个重主题**（v2 诊断实测 A1/A4 事实同构，硬拆 16 个"世界"是欺骗）：

|---|---|---|---|

| 2 | 瑞士国际主义（b1） | B1+B2+B3+B4 | IKB / 柠檬黄 / 柠檬绿 / 安全橙（B4"不满屏"预算口径随变体携带） |

### D4 · 差异化机器门槛（sync-themes 新校验）

- 每主题 G0 增必填字段"**分化声明**"：列出与最近邻主题实质分化的层（≥3 层，如 `L3/L4/L6`）+ 一句话说明。
- 校验器做**两两七层 diff**：L1=G1 token 集、L2=G2 规范化文本、L3=G3 token、L4=G9（css+词汇）、L5=G4 字段、L6=G5 签名字段、L7=G8 字段；任一对主题分化层数 <3 即非零退出（同一主题的变体间不查）。规范化口径：去注释、压缩空白、统一小写后做字符串比较。
- 变体字段集（定死，防解读漂移）：**变体名 + 一句话气质 + G1 六色 token（必填）+ 可选 G3 三 token 覆盖 + 可选 accent 预算注记**；变体不得覆盖 G2/G4/G5/G8/G9（字体/形态/动效/构图/母题与基底共享，否则它就是另一个主题）。
- 主题 CSS 块静态校验：选择器白名单（`:root` / `.mt-*` 及其伪元素/后代）、禁字面 hex、禁外部 `url()`。
- 底线声明（handover §5.5 接受）："一眼不同"是人工判断，机器门槛只保证三层分化声明为真。

### D5 · 想象层：隐喻库 + 呈现发散步（H 期）

用户点名"所有柱图都增长、数字都 count-up、对比都是左右、流动都是箭头"——病根是隐喻库只有一格。两个机制：

1. **`references/motifs.md`（隐喻库）**：按内容关系枚举发散视觉隐喻，每隐喻绑视觉语言 + 亲和气质 + 禁忌。首发覆盖八类关系：对比（裂屏/天平/拔河/赛道/镜像/前后对照）、增长（柱上升/阶梯/年轮/潮汐线/藤蔓）、流程（管道/河流/接力/渗透/循环）、数字呈现（count-up/翻牌/刻度盘/仪表/印戳）、层级、组成、因果、时间。枚举纪律不变（七件规范），枚举对象是隐喻而非版式。html-ppt-skill 的语义化 canvas FX（knowledge-graph/neural-net/chain-react/counter-explosion）仅登记为未来 fx 候选，本期不落码。
2. **SKILL.md 呈现发散步**：Step 1 页计划表加"呈现发散"列——仅关键页（封面/数据英雄/对比/流程页）强制，普通页豁免（控成本，handover §5.5）；Step 4 生成关键页时对该页关键内容块按 motifs.md 先写 3 个不同轴方案（尺度/隐喻/维度/动静/材质）再选定。发散文案留在页计划表，不进产物。

## 四、风险与对策

1. **母题 CSS 膨胀/失控**：上限 40 行/主题 + 选择器白名单机器校验 + 禁 hex 禁外部 url()；母题只许装饰（伪元素/border/背景），禁布局性覆盖。
2. **C2/D2 拉不开 3 层**：先认真分化（c2→植物图鉴世界：标本线描母题/学名标注/图鉴细描边卡；d2→暗房胶片世界：光束母题/显影式 blur-in 签名）；仍拉不开则合并为一个主题两个变体——**诚实优先于凑数**。
3. **发散步增加生成成本**：仅关键页强制，普通页豁免；发散文案进计划表不进产物。
4. **变体机制的面板复杂度**：变体只是主题卡上的色板切换，不增加问题数；导出走同一 JSON 通道。
5. **旧 deck 兼容**：v6 槽位对旧产物无要求；gallery 样张页组用 section 级注入，不动存量 24 页。
6. **分化门槛误伤**：门槛只查重主题两两，变体豁免；若某对主题确有正当近似理由，正确动作是合并为变体而不是放宽门槛。

## 四·补 主题立场三元模型（2026-09-20 用户定调）

美不是单一的——杂志风只是无数种美之一。主题各层立场只许清晰描述三件事：**① 必须有什么**（蓝图必须有网格纸）**② 美感通过什么形式表达**（信号黑靠色块压强而非线条）**③ 不能有什么**（杂志风出现玻璃拟态即违和）；**剩余部分是自由区**，由内容驱动的设计原则动态填充（密度双档、accent 预算、容器边界义务、注意力预算）。主题不得把自由区写死——反例：把"禁描边卡"这类结构需求当气质立场；高密度容器边界的**形式**由主题词汇承担、**要不要**由密度决定（用户裁决：面+框胜高密度、线/空胜低密度）。此模型写进 themes.md Schema 段，20 主题存量按此改写（消除结构禁、保留气质禁、补「高密度容器边界」字段）。

## 五、验收标准

- sync-themes 零告警通过；两两七层 diff ≥3 门槛生效（构造趋同对能被拦下，自验后还原）。
- harness 全绿（T9 更新；样张页组过 T18 零溢出零重叠）。
- 画廊样张页：9 主题同一封面内容肉眼可辨 9 种装饰/容器/质感语言。样张页型范围说明：G 期样张只做封面页——目的是验证母题/容器/质感机制可渲染、可区分；完整入库样张（封面 + 数据页 + 信息图页三页型，handover §5.3 第六步）是 I 期每主题入库时的验收标准，不在本期。
- 编辑器：主题卡变体可切换，导出意图含所选变体 tokens + theme_css + 双 SLOT 文案。
- SKILL.md 含呈现发散步且引用 motifs.md。
