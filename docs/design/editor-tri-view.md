# 编辑器 v3：三态工作台与翻转对比

> 状态：待评审 · 2026-09-21 · 总览见 `tri-form-architecture.md`；两个转换子技能见 `page-render-mode.md` / `pptx-export-svg.md`
> 依据：2026-09-21 用户意见——编辑器要与图片、pptx 两种形态融合，页面上能看到 HTML 与翻转产物的对比；"翻转"作为统一动词，探索翻面交互。

## 1. 定位

编辑器升级为**三态中控台**，但架构红线不变：纯静态、无 AI、**无转换逻辑**（转换即技能，见总览 §2）。编辑器只消费技能产出的 `export/` 目录与 manifest.json；产物不存在时展示引导（如何运行技能），产物过期时展示 stale 水印。

## 2. 顶栏视图分段：编辑 | 对比 | 导出

- **编辑**：现状不动（iframe srcdoc + 就地编辑 + 目录侧栏 + 批注）；
- **对比**：HTML 与翻转产物的对照工作台（§3–§5）；
- **导出**：页级清单（每页：形态 html/baked、载体 svg/png-fallback/baked 直通、保真分、fresh/stale）+ 产物下载（FSAA/下载；嵌入态走 postMessage）。导出面板**不发起转换**，只呈现最近一次技能翻转的结果与状态；stale 页的引导文案 = "请让 AI 重新翻转本页"。

## 3. 翻转：形态切换的心智层

"翻转"落为编辑器的一等交互：**当前页是一张双面卡**——正面是活的 HTML（可编辑），背面是同页的翻转产物（SVG 导出件或烙入图）。

- 交互：快捷键 `F` 或页面角标触发，CSS 3D `rotateY(180deg)` 翻面；`prefers-reduced-motion` 与降级路径为即时切换；
- **背面三态**（翻转需要时间，背面必须诚实表达"还没有东西"）：
  1. **就绪**：`<img>` 渲染 `export/page-NN.svg`（浏览器原生支持 SVG）；
  2. **过期**：产物存在但 hash 不符——产物照常显示，盖 stale 水印（§5）；
  3. **空态（黑面）**：该页从未翻转或产物缺失——背面渲染为**纯黑面 + 页码/状态一行小字**（"未翻转·生成需要 N 秒量级，请运行翻转技能"）。黑面是刻意的诚实空态：不用白屏装死、不用假进度条（编辑器不知道技能侧真实进度）；技能侧翻转完成后产物落盘，黑面在下一次打开/刷新时自然变为就绪态；
- 实现：预览容器双层结构（front = 现有 iframe；back = 三态容器），纯 CSS + 少量 JS，无依赖；双面需 `backface-visibility:hidden`，iframe 参与 3D 变换期间禁用其指针事件（防止翻面动画中误触编辑手势），动画结束恢复；
- **分层关系**：翻转是逐页的快速确认手势与过场（"翻过去长什么样"是最高频动作，匹配"同一页两个形态"的心智）；但人眼无法比较两个不同时可见的画面——**对比的落定形态是并排**（§4），翻转结束后/进入对比模式时双窗格并排呈现，翻转只负责心智模型与过场，质检永远在 §4 的同屏视图里进行。

## 4. 对比工具视图（质检层）

对比模式的**默认落定形态是并排**；三种同屏查看平铺切换：

1. **并排**（默认）：左活 HTML（iframe，仍可编辑）+ 右导出件（`<img>` 渲染 SVG），双窗格同步滚动、同步缩放；右窗格同样适用背面三态——产物缺失时右窗格显示黑面空态（页码 + "未翻转"状态行），与 §3 的翻面空态同一组件；
2. **滑动分割**：同页叠加 iframe 与导出件，拖拽分割线做 before/after 对刷，查局部走样最直观；
3. **差异热区**：叠加展示管线产出的 `export/page-NN.diff.png` 热力图——**编辑器自身无栅格化能力**（纯静态 + 零依赖红线，无法截图跨文档 iframe 内容，禁止引入 html2canvas 类库），热区资产只能由导出管线在算保真分时顺带产出，编辑器只消费。定位"哪里不像"，不停留在"像不像"。

**保真分闭环**：导出管线 postflight 已将每页像素 diff 分写入 `export/manifest.json`；对比视图页清单按保真分排序（红→绿），点击跳转——兼容性从感觉变成数字，与 harness `m_fidelity_check.py` 共用同一数据源。

## 5. stale 闭环与烙入页

- 编辑任一文字 → 保存时重算 `data-content-hash` → 与 `export/manifest.json` 记录不符 → 该页背面盖**"已过期"水印**，导出面板同步标 stale；
- **烙入页的对比**：背面是烙入图，正面提供"源层编辑"入口——打开 `.baked-source` 隐藏层进行文字编辑（保存即翻转 hash → 烙入图 stale → 提示重新烙入）。烙入页正面默认锁就地文字编辑（文字在图里），图像替换走既有换图流；
- 缩略图侧栏页徽标三分量：形态（HTML/烙入）、状态（fresh/stale）、保真分（绿/黄/红）。

## 6. 嵌入态与降级

- postMessage 协议扩展（最小集）：出 `pptx-html:export-intent`（用户点击"重新翻转"，编辑器不执行，仅通知宿主）；入 `pptx-html:load` 既有消息扩展可选字段 `exportManifest` / 产物 URL 基址。转换是否发生、何时发生，由宿主侧 AI 工作流决定；
- 无 `export/` 产物（从未翻转）：对比与导出页展示引导文案，不报错；
- 无伴随服务/纯文件打开：照常读相对路径 `export/`，全部功能可用——产物即文件，不需要运行时后端。

## 7. 验收标准

- 翻转交互：fixture deck 翻转动画正常、reduced-motion 即时切换、front 编辑态不丢；背面三态逐一验收（就绪渲染 SVG / 过期盖水印 / 无产物显示黑面空态且含状态文案，黑面不伪装加载中）；
- 对比默认落定：进入对比模式即并排双窗格；无产物页右窗格为黑面空态；
- 三视图：并排同步滚动缩放；滑动分割双端对齐；热区与保真分数据同源（构造已知差异页，热区红框必须落在差异处）；
- stale 闭环：改字保存 → 水印出现；重新翻转（技能侧重跑）→ 水印消失；
- 烙入页：正面文字锁 + 源层编辑 + 换图流可用；源层编辑 → 烙入图 stale；
- 降级：删除 export/ 后对比/导出页为引导态；嵌入态 `export-intent` 消息格式校验；
- harness：`m_fidelity_check.py`（保真分阈值 + hash 指纹过期检出）纳入回归。
