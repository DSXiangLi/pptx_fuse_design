# 视觉纵深设计：高级感要素 × 组件库 × 动效词汇库

> 状态：待评审 · 日期：2026-09-19 · 依据：`../research/v2-effect-diagnosis.md`（效果问题定位）+ 归藏设计要素深潜 + 动效类型空间穷举（两轮调研，2026-09-19）
> 回答三个问题：① 优秀设计的要素是什么（归藏拆解）；② 信息图/图表要不要单独组件库；③ 动效能否完整穷举。

## 一、高级感要素（归藏拆解的结论）

归藏的高级感 = **极度克制的材料清单 × 极端的尺度对比 × 仪式化的节奏控制**。拆成 8 条可检查要素（每条都有实测证据，详见调研记录）：

| # | 要素 | 可检查形式 | 我们的现状 |
|---|---|---|---|
| 1 | **双色墨水 + 单一锚点色，accent 有用量预算**：内容页 accent 面积 ≤10%，满屏 accent 是封面/收束的特权；首（全亮）尾（半亮）色彩闭环 | 渲染截图量化 accent 像素占比 | ❌ 我们的"克莱因蓝"封面是黑底+24px 蓝条——accent 只做针线没做面料 |
| 2 | **字重阶梯倒挂**：越大越细（≥8vw→200）、越小越粗（小标 500-600），同页小字字重 ≥ 大字 | 字号×字重对照表静态校验 | ⚠️ typography.md 有原则但比归藏软 |
| 3 | **极致字号对比 ≥8:1**：巨字 `min(Xvw, Yvh)` 双约束限高 | 字号比静态校验 | ⚠️ 我们的标题：正文约 3:1 |
| 4 | **Hairline 即全部装饰结构**：1px、低透明、只在层级边界 | 规则已有 | ✅ 有但滥用倾向未校验 |
| 5 | **容器四档明度（纸/灰/墨/accent）直角纯色，单焦点**：一组卡片只许一张 accent；灰底与纸白低对比"靠空气不靠边界"；禁渐变/阴影 | 组件配方 + 校验 | ❌ 我们的容器=带边框文本块 |
| 6 | **刊头家具三件套**：mono 大写加宽字距页眉 + 页脚 + 编号角标（编号替代图标） | 骨架槽位 | ❌ 我们只有一行 kicker，无页脚家具 |
| 7 | **背景配给制**：正文页纯色；程序化背景（ASCII 呼吸场/点阵/纹理图）只许 hero/封面/封底 | 骨架机制 + 主题 G3 | ❌ 质感槽位建好了但主题全没填 |
| 8 | **构图谱系**：归藏 22 版式可归并为 6 谱系（巨字宣言/数据英雄/网格矩阵/轴与节点/图文证据/裂屏对开），张力来源分别是尺度对比、字号差+不等高几何、秩序+单焦点破序、线的引导、满幅 vs 网格、色彩对撞 | 谱系枚举 + 节奏规则 | ❌ 我们只有"左上标题+内容带"一种 |

**关键转化**：这 8 条不是"反雷同检查"能替代的——雷同是结果，根因是**要素库存里没有货**。修复方向 = 把 8 条要素分别落到已有结构的对应层：1/2/3 → themes.md（主题 Schema 补充 accent 预算、字重映射、字号比）与 typography.md；4/6 → skeleton 框架层（页眉页脚家具槽位）；5 → 组件库容器规格（见下）；7 → skeleton 质感槽位 + 主题 G3 填充 + 背景配给规则；8 → components.md 升级为"构图谱系"（6 谱系取代平铺族，每谱系带张力来源说明与示例）。

## 二、信息图/图表组件库：有必要，且要建成"画廊 + 配方"双形态

**判断：有必要单独建。** 理由：v2 诊断证明配方条文抬不动 AI 的下限——AI 模仿的是见过的最好例子，不是规则。组件库是"丰富度标定资产"：每个枚举项配一个**高复杂度参照实例**（可直接抄的具体样子）+ 验收标准。

**形态设计**（避开 dashi 1020 模板陷阱的关键）：

```
skills/html-pptx/
├── references/components.md      # 配方层（结构族×皮肤，已有 v2）
├── references/charts.md          # 图表配方（扩类型，见下）
└── gallery/                      # 【新增】实例层：可浏览的组件画廊
    ├── index.html                # 画廊 deck 本身（skeleton v3 产物，可演示可验收）
    └── 每页 = 一个枚举项的高复杂度实例
```

- **枚举对象不膨胀**：库的内容仍然是 6 结构族 × 6 皮肤 + N 图表类型——每个**组合**给一页高复杂度实例（含连接件语义层次、数据墨迹、标注层、材质叠印），实例页本身遵守全部契约（可编辑标记、槽位、动效）；AI 生成时读配方 + 看实例，两手都有；
- **图表扩类型**：现有 4 配方扩为：柱/条（含堆叠、分组）、折线（含面积、scrub 描绘）、环/饼、进度、**瀑布、散点/气泡、雷达、斜率图、漏斗、热力表格**。每类型配方必须带**标注层规格**（参考线、区间带、数值直标、注释旗标）——"能读数"到"讲故事"的差距就在标注层；
- **入库走七件规范**（sota-visual-languages.md）：实例页即"渲染可验"的载体，画廊 deck 直接进 harness 回归；
- **组件库与主题的关系**：实例页用哪个主题渲染需要定规则——建议每个实例页用其最亲和主题，且实例页内容器规格（明度档/单焦点/出血通栏）按要素 5 落地。

## 三、动效穷举：类型空间有限可枚举，词汇库升级为 8 族

动效类型空间按"触发 × 对象 × 机制"三轴穷举后是**有限集**（11 族），按约束（单文件零依赖/竖滚/可编辑/reduced-motion/iframe 嵌入）过滤后分三档：

- **可直接做**（纯 CSS / 骨架现有 JS，一次骨架升级）：blur-in、scale-pop、wipe/iris 揭示、mask-lines 逐行遮罩、gradient-flow 流光字、fill-bar-y 竖柱、ring 环形进度、dash-flow 流动虚线、flow-dot 沿线粒子（offset-path）、hover 全家、**pin 钉住 / stack cards / cover-uncover（sticky 纯 CSS）**、**parallax / scrub 滚动驱动（CSS scroll-timeline，零 JS）**、god rays / 漏光、噪点、渐变球、kenburns、marquee、3D 透视入场；
- **要加骨架机制**：pointer tracker（光标聚光/tilt/磁性/指针视差，~50 行 rAF + CSS 变量，不碰 DOM 零编辑冲突）、canvas FX runtime（星座/星空轻粒子，密度上限烧死，~150 行，**这是对"氛围背景不进骨架"决策的合理重评——canvas 2D 轻粒子与 WebGL 流体是两个量级**）、文本引擎扩展（typewriter/scramble 走运行时化）；
- **不建议做**：WebGL shader 背景、全屏页间转场、scroll-jacking、自定义光标、循环文字动效、音效、第三方动效库。

**词汇库结构**：8 族 ~32 recipe，族前缀即触发器自文档化（`enter-*` / `text-*` / `data-*` / `link-*` / `amb-*` / `light-*` / `ptr-*` / `scroll-*`），参数化方向/强度（不学 ppt-master 203 种扁平排列——但它的"职责先行 + 默认全关 + 反目录覆盖"三条元纪律直接吸收）。

**丰富度档位重定义（解决"两份 deck 动效感觉一致"的核心）**：从"同层参数微调"改为**五层启用矩阵**——L1 入场编排 / L2 文字动效 / L3 数据动效 / L4 环境层（amb+light+粒子）/ L5 交互层（ptr+scroll）。克制=L1；标准=L1–L4 各一；华丽=五层全开。**档间差异是机制类别本身不同，不是强度不同**——两份不同档的 deck 一动就能感到差异。注意力预算三档共享不变（华丽档加的是层不是同层数量），保持机器可验（按族计数）。

## 四、实施分期建议

| 迭代 | 内容 | 依赖 |
|---|---|---|
| F1 | 高级感要素落位：themes.md 补 accent 预算/字重映射/字号比；skeleton v4 加刊头家具槽位 + 背景配给机制；typography.md 硬化 | 无 |
| F2 | 组件库画廊：components.md 升"构图谱系"叙述 + gallery/ 实例页（每族×皮肤一页高复杂度实例）+ 容器明度规格 | F1（容器规格依赖主题 accent 预算） |

| F4 | 动效词汇库 8 族：skeleton v5（scroll-timeline + pointer tracker + 文本引擎扩展）+ motion.md v3 + 五层启用矩阵接面板 | 独立，可与 F2/F3 并行 |
| F5 | canvas 粒子 FX（默认关，主题 G5 声明启用） | F4 之后单独评估 |
