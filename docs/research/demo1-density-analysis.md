## 二、结论：密度的断层在「微字标注层」，不在容器也不在字阶

我们的 K 期 deck 容器分型对了、字阶极值比不差，但 **demo 每屏有 21–54 个 9–13px 的 mono 微字文本**（标签/单位/序号/元信息/来源注/状态），我们是 **0**——我们的 mono 最小只用到 14–15px 且只在家具位。这个微字层就是"印刷级密度"的来源：demo 看起来信息量是 3 倍，多出来的部分几乎全是标注。

**demo 的字阶频谱是连续的**：216/72/44/20/18/13/11/10——从巨字到微字中间没有断档。我们的频谱两头粗中间细：巨字和正文有了，标注层整层缺失。

## 三、提炼：高密度五条范式

1. **微字标注层合法化**：高密度 = 正文层（≥18px）+ 标注层（12–16px，画布坐标）双层制。标注层必须 mono + 低明度（40–65%）+ 短文本（≤20 字符）+ 拉丁大写宽字距——它退为"印刷肌理"，不是阅读对象。每个容器 2–4 处标注（标签/单位/序号/来源/状态）。
2. **密而不乱 = 明度分层，不是留白分层**：微字层全部退到 40–65% 明度（demo 的 --dim/--fg-2 两级灰），页面焦点仍然只有 1–2 个（巨字 + 单 accent）。高密度下"主次"靠明度阶和字号极值比维持，不靠减少信息。
3. **容器嵌套密度目标**：高密度页 3–5 个容器区/页、每容器 4–6 信息件（tag/题/体/注/指标）；容器内部结构全 deck 同构（四层字阶），容器之间用 hairline/明度差分隔，负空间留给容器之间，不留在容器内部。
4. **字阶频谱连续**：高密度页字号档 ≥8 档且连续覆盖 巨字/标题/小标/正文/标注 五区，中间不断档（§13 四层字阶 + 标注层细分）。
5. **高密度动效配额**：每屏主动效仍然只有 1 个（注意力预算不变）；但**容器级微动效**随容器数增加——每容器至多 1 个、语义优先（mend-bar 修复、data-rotate 轮转、count-up 落差）、循环类微动效全屏 ≤2。密度越高，动效越往"语义型"集中，越远离"氛围型"。

## 五、动效层代码级复盘（第二轮，读 `方向B 极黑冷调.html` 实现而非 README）

用户验收驱动：我们 v2 的动效问题——全 deck 标题清一色相同动效、背景与装饰层无动效。demo1 代码实测回答：

**标题动效的真实结构是两档制，不是每页换款**：

- Hero 标题用全场最强的 shatter（字母散落聚合：±400px 位移/±45° 旋转/1.4–3× 缩放/14px blur/逐字符 48ms+jitter 错峰）——它是唯一的；
- 全部章节标题用**同一款** split-char（逐字符 24px 上浮 + blur 6px + i*22ms 错峰 capped 700ms）——章节标题同款是**对的**：一致性=系统感；
- 关键差异在**质感参数**：我们的清一色 wipe-clip 是"色块揭示"款，职能上用错了对象（wipe 的对象是色块不是文字）；且与正文入场拉不开档次——章节标题必须比正文"贵"（逐字符错峰+微模糊 vs 整块 fade）。

**背景与装饰层的隐性运动清单**（demo1 实测全在开）：gridDrift 底纹 60s background-position 漂移（最便宜的活态）、footBreath 水印 8s 呼吸（opacity .04↔.08）、baBreath 边框 3.2s 呼吸光、brand-dot 2s 光晕环、livePulse 状态灯、numGlow 编号呼吸（hover 触发）。"活着的密度"= 标注层（静态）+ 装饰呼吸（低频）+ 语义微动效（容器级）三层叠加——我们只有后一层的语义件，前两层都缺。

**回灌**（motion.md §6 新增）：标题动效两档制【默认】+ 背景隐性运动全局选型【默认】（L4 代表优先选全局款而非只放封面；装饰呼吸计入每屏 ≤2–3 背景预算）。验收：smartforge-c1 动效修正（v3）。

## 六、字体层代码级复盘（第三轮）

demo1 的字体层是**四字体分工制**，且"艺术字体效果"的大头不是字体文件而是**文字处理（treatments）**：

1. **display 性格载体**：Bebas Neue 窄体大写贯穿五个量级（240px hero → 180px 章节 → 48–56px 卡片题 → 80–120px 装饰编号 → 44px from 值）——同一 display 字体跨量级复用是"性格统一"的来源。系统栈给不了窄体（真实差距），因此 G2 新增可选「display 联网备选」字段（离线方针不破：仅用户接受联网时加载，fallback 与系统栈气质同构）。
2. **字重 300 正文档**：demo 正文是 300 细体（大留白 + 细体 = 高级感来源之一），我们字重映射表此前无 300 正文档。
3. **文字效果词汇**（纯 CSS 离线无害，demo 全在用）：描边字 + 填充/描边混排标题（"SMART 填充 + CONTENT 描边"是 demo 的签名手法——描边词充当背景层，填充词是焦点）、删除线 from 值（¥2,000→¥0 的 ¥2,000 画 3px 删除线——"被取代物"的语义处理）、accent 下划线/荧光标记关键词。

**回灌**（skeleton v7.1 + typography.md §7 + 契约 v6.4）：`.tt-outline`（描边字，--tt-c 色槽位）/ `.tt-strike`（加粗删除线）/ `.tt-mark`（荧光标记）/ `.tt-uline`（粗下划线）四款进骨架框架层；描边字编辑态还原本色（同 gradient-flow 条款）；主题 G2「标题修饰」声明亲和/禁忌（c1 已声明混排+删除线亲和）；themes.md Schema G2 行补「display 联网备选」可选字段。验收：smartforge-c1 v4（封面混排标题 + ticker 删除线 from 值 + 痛点 mark + 收束 uline）。
