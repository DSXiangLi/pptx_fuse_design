# v2 效果验收问题定位（诊断，非修复）

> 日期：2026-09-18 · 触发：三个 v2 deck（tech-ikb-v2 / culture-kraft-v2 / launch-mono-v2）视觉验收不通过
> 方法：15 张关键页渲染截图 + 像素级墨迹/色板/纹理分析 + 三个 deck HTML 全结构解剖 + 归藏 swiss 模板实际渲染做"高端感"基准对照。本文只做归因，不开处方。

## 0. 直接回答"一致感从哪来"

三个 deck 主题不同（色、字不同），但视觉上像一种风格。一致感的来源是四个"同一个"：

1. **同一个安全框与构图吸引子**：三 deck 共用骨架的 `--slide-pad:96px 120px`；39 页里 38 页是同一构图——左上 mono kicker（18-20px、letter-spacing .12em）+ 64-72px 大标题 + 下方一条 flex/grid 内容带；三张封面全是"暗底 + 左侧纵列文字 + 右侧一件低透明装饰"。像素墨迹图证实：15 张截图的底部 20% 与最右一列**全部为空**——留白不是设计出来的，是同一个默认值。
2. **同一个淡入**：骨架默认 reveal/data-anim 就是 `opacity:0 → translateY(24px)`；每 deck 约 80% 的动效元素是这同一个淡入。特色 recipe 的分配在三 deck 形成**完全相同的"配额指纹"**：封面 chars×1、draw-line 固定配给图表/循环图、count-up 固定配给 KPI 页、fill-bar 固定配给进度条页。"两个 deck 动效感觉一致"不是感觉，是事实。
3. **主题之间只差色和字，且字也没拉开**：A1 与 A4 的 G2 字体栈逐字相同、G5 动效气质同为 editorial、accent 都等于 ink；A4"牛皮纸"连 G3 纸纹 token 都没定义（三 deck 的 `:root` 里都没有 `--texture-layer`，实测纹理能量与平色页持平）；B1 与 A1 的暗页底色是 `#0a0a0a` vs `#0a0a0b`——数值上同一个黑。主题 Schema 有 G3–G8 字段组，但这几个主题的字段是空的。
4. **同一套装饰语言**：1px hairline、残影大字、描边圆环，三 deck 通用。

## 1. Q&A：视觉预研是否站得住脚？

**方向站得住，执行深度没站住，且调研结论有一处需要修正。**

站得住的部分：决策前置、token 系统、容量先于版式、可编辑契约——这些保证了产物"不破"（零溢出、可编辑、幂等），验收 harness 证明了这一点。

没站住的部分：调研结论保证了"不垮"，没有保证"出彩"。我们拿了归藏的主题纪律，**没拿它的版式丰富度机制**——归藏一个瑞士主题就有 22 个登记版式（裂屏巨字、不等高 KPI 塔、通栏 ink 条、点阵宣言……）且每页强制声明 `data-layout="Sxx"`；我们 39 页实质只有约 4 种版式。

需要修正的调研结论：source-survey.md 当时把"22 个锁死版式的枚举教法"列入**明确不拿**。诊断证明这是把洗澡水和孩子一起倒了——锁死版式确实压抑表达，但**完全没有版式层的分布约束，AI 就收敛到同一构图吸引子**。正确形态不是"枚举版式"也不是"完全自由"，而是中间态：版式谱系 + 反雷同约束（详见 §5 根因 1）。

## 2. Q&A：信息图为什么"最基础"？

归因三层：

- **配方是最小形态**：components.md 六族定义的是骨架合法性（可静态校验的那层），每个族的示范实现是"线+点+文字"的最简形态——timeline = 一根 1px 线 + 圆点 + 年份；同心圆 = 4 个描边 circle；闭环 = 1 个圆 + 4 个箭头。没有复杂度的上限参照，AI 自然取最小公倍数；
- **缺丰富度的构成维度**：连接件没有语义层次（所有线同族 1-2px，只靠 opacity 分档）、图形不承担数据墨迹、没有非对称与破格（全部居中/均分）、没有材质与图层（无填充面、无叠印、无底色块）；
- **主题没给组件加成**：G8 组件亲和字段空置，组件在所有主题下长一个样。

## 3. Q&A：图表类型与 preview gallery 的必要性

**类型少是事实**（四配方：柱/条/折线/环 + 进度），但比类型数量更缺的是**完成度**：现在的图表"能读数"但不"讲故事"——无参考线、无区间带、无数值直接标注、无注释层。

**preview gallery 有必要，且定位要准**：它不是给用户看的样张集，而是**丰富度标定资产**——为每个信息图族 × 皮肤、每个图表类型生成一个"高复杂度参照实例"，连同验收标准一起入库（正好走 sota-visual-languages.md 的枚举七件规范）。它的作用是抬高 AI 的下限参照：AI 模仿的是它见过的最好例子，不是规则条文。归藏的 22 版式之所以有效，一半因为约束，一半因为它是**可以抄的具体样子**。

## 4. Q&A：动效为什么贫乏且趋同？

- recipe 词汇表有了（chars/shatter/count-up/draw-line/fill-bar），但**编排决策收敛**：recipe→内容类型的映射在三 deck 逐一对齐（§0.2 配额指纹）；
- 缓动/时长全部走同一套骨架 token（这是 v2 设计的纪律，副作用是节奏同质化）；
- **G5 动效亲和声明了但没分化**：三个主题的动效气质几乎一致，没有"主题动效签名"——A4 牛皮纸理应更慢、更缓、有纸张式的物理感；B1 瑞士理应锐利、精确、短促。现在它们动起来一模一样；
- chars 拆字只用于封面一处，张力止步首屏。

## 5. 根因排序

| # | 根因 | 权重 | 证据 |
|---|---|---|---|
| 1 | **AI 构图分布收敛**：骨架只提供一套默认引力（安全框/左上标题/淡入），版式层无任何分布约束，AI 每次落进同一吸引子 | ~一半 | 38/39 页同构；动效配额逐 deck 对齐；组件选择收敛到相同 3-5 族 |
| 2 | **主题规格太薄**：Schema 有 G3–G8 但存量主题大面积空置；A1/A4 事实同构 | 结构性 | 字体栈逐字相同、无质感 token、暗色底数值相同 |
| 3 | **组件/图表配方是最小形态**，无高复杂度参照实例 | 次级 | timeline=线+点；图表无标注层 |
| 4 | **动效无主题签名、编排收敛** | 次级 | 配额指纹；缓动 token 单一 |

## 6. 修复方向（排序，仅方向不展开——待用户确认后立项）

1. **版式层引入分布约束**：不恢复锁死版式，改为"构图谱系 + 反雷同校验"——定义版式维度（重心位置/明暗/构图骨架/密度形态），生成时校验同 deck 内版式分布不塌缩（如连续两页同重心同骨架即违规），把"连续两页构图雷同就是失败"从口号变成可检查项；
2. **主题纵深填充**：A1/A4 解耦（字体栈、质感、动效签名差异化）、G3 质感实装到存量主题、主题级构图倾向（G8 扩展）；
3. **信息图/图表 preview gallery**：每族×皮肤、每图表类型一个高复杂度参照实例 + 验收标准，作为 skills 资产入库（charts 扩类型：堆叠/面积/散点/瀑布/雷达/漏斗/斜率等按需求优先级）；
4. **动效主题签名**：G5 从"禁用清单"升级为"签名配方"（时长/缓动/编舞密度的主题级参数），同一 recipe 在不同主题下气质不同。
