## 偏离与裁定

1. **画廊封面质感微调**：A1 的 `--texture-layer` 是 ink 6% 晕染，在 dark 封面（墨底）上不可见；封面改用 paper 8% 同构渐变。属仪式页的合理变体，非主题 token 修改（token 块仍逐字来自 themes.md）。
2. **S10 象限页删去虚线对角参照线**：初版对角线穿过两个象限的说明文字（像素复核发现），判为噪声删除；该页连接件层次由十字轴 + 轴端标注承担。
3. **谱系节奏的机器可验口径**：§11 硬规则的本体是"生成侧规划清单逐页标注"；画廊额外把谱系写进 mastfoot 右槽，T18 借此做了实例级回验——普通 deck 不要求 mastfoot 必须标谱系（家具内容仍是自由 SLOT）。
4. **画廊无图片槽位**：图文证据谱系的"证据块"用纯 SVG 标本图实现（组件画廊的主题是信息图结构而非图片）；图片契约已由契约 v5 与 T16/T17 覆盖，不重复造验。
5. **T18 用 content-visibility 强制排版后测量**：骨架 `.slide-slot{content-visibility:auto}` 下远屏页不排版，测量前统一置 `visible`（仅测量会话，不进产物）。
