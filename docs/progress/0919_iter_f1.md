## 变更清单

### 1. themes.md（16 主题全部补齐三处）

- **G1 新增「accent 预算」字段**（要素 1）：每主题写明内容页 accent 面积上限（B/C/D 系 ≤10%，C2/D2 点睛型 ≤5%）、满屏 accent 特权页（封面/收束；B4 安全橙特权形态收窄为通栏条带 ≤20% 高、C3 满屏绿禁止）、首尾色彩闭环建议（全亮开场 → 半亮/条带收束）。A 系 accent==ink，"满屏 accent"落为暗色反白页口径。
- **G2 新增「字号对比」与「字重映射」字段**（要素 2/3）：B 系严格照归藏倒挂阶梯（≥154px(≥8vw)→200 / 77–153→200–300 / 35–76→300–400 / 17–34→400–500 / 14–16→500–600）；其余主题给量化映射表（见"偏离与裁定"）。
- **G3 立场必填并填充**（要素 7）：A1 墨韵 glow / A2 瓷光 glow / A3 林间颗粒 grain / A4 牛皮纸纹 paper（噪点 data-URI + 横向细纹 + 渍晕，scope:all）/ A5 沙粒 grain；B1–B4/C1/D1 显式 flat（写明"flat 即质感立场"）；C2/D2 glow（已有）；C3 CRT 扫描线 grain（scope:all）；C4 轻纸纹 paper；D3 paper（已有）。纹理一律 CSS 实现（渐变/噪点 data-URI），零图片资产。

### 2. typography.md 硬化

- §3 字重阶梯升级为**量化映射表【硬规则】**（归藏口径，px+vw 双标注），新增两条配套硬规则：同页倒挂（小字字重 ≥ 大字）、小字可读性下限（14–18px 禁 300，最低 400 推荐 500）；衬线 display / C1 极粗标题作为主题级例外立场显式声明。
- §5 密度双档的"字阶"行升级为**字号对比档硬规则**：低密度主标题:正文 ≥8:1（巨字 `min(Xvw, Yvh)` 双约束限高）；高密度 ≥5:1（信息承载优先，不硬套 8:1）。

### 3. skeleton v4（`assets/skeleton.html`）

- `<meta name="skeleton-version" content="4">`。
- **刊头家具槽位**（要素 6）：`.masthead`（左 kicker 位 / 右页码或日期位）+ `.mastfoot`（页脚 hairline 元信息行）样式进框架层（mono 大写加宽字距、低透明、hairline 用 `color-mix(currentColor 22%)` 兼容明暗页）；定位烧死在 `--slide-pad` 内边距带内；结构与内容是可选 SLOT（示例页已演示，家具文字标 `data-editable`），仪式页建议省略。中文家具内容由生成侧将 letter-spacing 归零（注释写明）。
- **背景配给制**（要素 7）：质感层 `.slide::before` 默认 `background:none`，仅 `.cover-page` / `.texture-on` 两类页铺；v3 的 `texture-cover` JS 机制移除（纯 CSS 配给、零运行时状态），`--texture-scope` 降级为主题级许可声明（cover=只许仪式页 / all=允许正文页但仍需逐页 `.texture-on` 落码）。
- v3 全部能力（拆字引擎 / count-up / draw-line / fill-bar / ambience / 缓动 token / 降级链）原样保留。

## 偏离与裁定

1. **字重倒挂不一刀切**：归藏阶梯源于瑞士无衬线；衬线 display（A 系/C2/C4/D2/D3）细字重大字号发虚、C1 信号黑以"标题极粗"为立场、C3 等宽无细体、D1 圆润体不用极粗——这些主题给量化映射表但**不走倒挂**，例外立场显式写进各自 G2 字重映射与 typography.md §3 的例外条款。倒挂阶梯的强制执行范围 = B 系及未来无衬线 display 主题。
2. **`--texture-scope` 语义变更（v3→v4 骨架级 break）**：从"JS 自动开关"改为"主题级许可声明 + 生成侧逐页 `.texture-on`"。存量 v3 deck 不受影响（骨架逐字内嵌、不追溯）；编辑器净化天然兼容（纯 CSS 无运行时状态）。
3. **G3 从可选升级为立场必填**：超出 visual-depth.md 字面（该文只要求"填充空置 G3"），但"flat 也要显式写出"才能让校验器区分"立场是 flat"与"忘了填"——已同步 theme-schema.md 与校验器。
4. **C3 扫描线 / C4 轻纸纹为本次新增质感**（任务点名 A 系与 flat 立场，C1/C3/C4 未点名）；为达成"立场必填"必须给全，C3 扫描线强度已烧死在 token（ink 4% 1px/4px）。
5. **刊头家具未进存量 deck**：家具是 v4 骨架的可选 SLOT，F1 只落骨架机制与示例页；存量 deck 不追溯（与骨架升级纪律一致）。F6 重制三风格 deck 时启用。
