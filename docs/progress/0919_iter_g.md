## G 期：主题 = 七层表达力栈

**Schema（themes.md 全面重写）**：九字段组 G0–G8 → 七层表达力栈 L1–L7 ↔ G0–G9。新增：G9 装饰母题（词汇清单 + 主题自带 CSS 块）；G4 扩「容器造型语言」；G5 扩「动效签名」（锚点偏好/节奏偏移/缓动签名）；G8 扩「谱系偏好与禁忌」；G0 新增三必填（世界参考 / unforgettable / 分化声明）。

**两级主题架构**（html-ppt-skill 教训落码——15 行纯调色板主题是没有质感/容器/字排层的下场）：存量 16 个"主题"诚实合并为 **9 个重主题 + 3–5 套配色变体**（变体=同一世界的不同光线/时辰/材质，只许覆盖 G1 六色 + 可选 G3）：

- A1 电子杂志（收编原 A1–A5 为 5 变体：墨黑/靛蓝瓷/森林墨/沙丘/牛皮纸）——母题：Ghost 残影巨字/竖排题字条/墨点
- B1 瑞士国际主义（收编 B1–B4：IKB/柠檬黄/柠檬绿/安全橙）——母题：加号角标/网格点阵/色块编号；缓动签名锐利化
- C1 信号黑（信号橙/赛博青/警报红）——母题：信号条/巨号页码/信号方块；过冲缓动 + scale-pop 签名
- C2 暗夜植物园（暖金/月白/苔绿）——世界=植物标本图鉴：引线标注/编号签/拉丁学名/叶脉线；draw-line 生长签名
- C3 终端绿（绿磷光/琥珀磷光/白磷光——CRT 磷光体忠实采样）——母题：ASCII 框/闪烁光标（复用骨架 tw-caret）/提示符；typewriter/scramble 签名
- C4 纸与墨（绯红/藏青/黛绿）——母题：题花/首字下沉/引文拉页
- D1 奶油物语（焦糖/抹茶/莓果）——母题：贴纸徽章/扇贝花边/奶油圆点；回弹缓动 + scale-pop 签名
- D2 柔光暗房（琥珀/银盐/安全灯红——暗房安全灯即红色）——母题：胶片齿孔/光束角标/显影晕；blur-in 显影签名 + 浮出缓动
- D3 手绘油彩（赭石/雾蓝/灰绿）——母题：笔触块/虚线圈注/画框双描边

**c2/d2 诚实判断**（曾是最危险撞脸对）：分化成立——L5 容器逻辑对立（线边界 vs 光边界）、L6 签名方向对立（生长 vs 浮现）、L4 词汇来自两个互不相干的世界；但分化全押在 L4/L5/L6 执行忠实度上，已列为 I 期撞脸矩阵首批肉眼 diff 对象。

**骨架 v6**：新增 `SLOT: theme css`（框架层之后、`</style>` 之前）——主题获得 CSS 规则通道：`:root{}` token 重定义（缓动签名借此零骨架改动生效，框架全用 var() 消费）+ `.mt-*` 母题类（全库唯一命名空间）。三类规则白名单、禁字面 hex、禁外部 url()、禁覆盖框架选择器。meta skeleton-version 5.1→6。旧产物（v3–v5.1 骨架）不受影响、不强制回填。

**机器门槛（sync-themes.mjs 重写）**：两两七层 diff ≥3 层实质分化（L3 只比 texture-type+scope，防"同 glow 微调参数冒充分化"）；分化声明逐层核验为真（声明 vs 最近邻的每层签名必须确实不同）；变体 ≥2/主题（基底+变体 ≥3 套配色）；G9 css 白名单/禁 hex/禁外部 url()/禁 @keyframes（可引用骨架已有 keyframes）；.mt-* 全库唯一。否定测试已验证（构造 a1 双胞胎被 6 项错误拦下）。面板数据新增 variants[] 与 theme_css 通道。

**编辑器 v2.3**：主题卡新增变体色点行（点击切换、再点回基底）；面板分组新增「装饰主导」（focus=G9）；导出意图 JSON 携带变体合并 tokens + theme_css，文案改双 SLOT 口径。

**联动**：components.md §12 硬规则 2 改写（容器造型一律委托主题 G4/G9，§12 只管明度档/单焦点/互斥）；motion.md G5 接口扩签名（注意力预算仍是硬上限，签名只在预算内定倾向）；editing-contract v6.2（主题 CSS 块原样保留 / .mt-* 母题件 skip / 文本载体类母题的文本保持可编辑 / 主题块 :root token 重定义禁净化）。
