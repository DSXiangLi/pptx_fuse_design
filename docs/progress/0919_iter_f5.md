# 迭代 F5：canvas 粒子 FX 仪式层（skeleton v5.1 + 契约 v6.1）

> 日期：2026-09-19 · 依据：`../design/visual-depth.md` §三（canvas FX runtime 属"可做但要加骨架机制"档——"canvas 2D 轻粒子与 WebGL 流体是两个量级，前者可进，后者维持不做"）§四（F5：默认关、主题 G5 声明启用、独立评估）
> 结果：harness 37/37 全绿（基线 36 → 新增 T21 canvas FX 全生命周期）

## 评估结论（先行）：三条红线全部守住 → 落地

| 红线 | 结论 | 依据 |
|---|---|---|
| ① 产物纯净（单文件零依赖） | ✅ 守住 | canvas 2D 是原生 Web API，零依赖；产物文件中的 `<canvas data-fx>` 是**空元素**（无 width/height、无内容）——首次入视口才初始化位图尺寸，从未入视口的 canvas 零残留；像素绘制不属 DOM 状态，序列化天然不含。单文件交付形态不变 |
| ② 注意力预算（上限烧死） | ✅ 守住 | 效果集收敛 4 款（constellation/starfield/particle-drift/ascii-field）；密度/数量/速度/透明度上限全部烧死在骨架 `FX_DEFS` 常量，**无任何参数通道**（无 data-* 参数位，生成侧只能选类）；页面级配给=背景配给制的动效版（只许 `.cover-page` 仪式页、每页至多 1 个、全 deck ≤3 页，motion.md 硬规则）；主题 G5「fx 许可」白名单默认关 |
| ③ 降级链完整 | ✅ 守住 | reduced-motion 整组不初始化（fxList 恒空，canvas 恒空白）；无 JS 环境 canvas 是透明空元素；打印额外 `display:none`；iframe 嵌入零事件监听（不碰 pointer/scroll，只复用既有 fit() 缩放挂钩），不劫持宿主；编辑器 freeze 停帧+清屏+摘除尺寸 |

先例正当性：guizang `template-swiss.html` 的 ascii-bg IIFE（canvas 2D 呼吸场，IKB 封面/封底专用）证明轻量 canvas 场效果与"高级感"兼容；open-design 的 FX 清单证明 `data-fx` 声明式接口成立。WebGL 流体/ shader 背景维持"不做"结论不变。

## 偏离与决定

1. **版本号取 v5.1（patch）而非合入 v5**：canvas FX 是新增机制层，版本号可见性有助于存量 deck 识别骨架能力；T19 断言同步更新。框架层 CSS/JS 对无 fx 的 deck 零行为差异（fxList 为空、CSS 仅一条 `[data-fx]` 垫底层规则）。
2. **fx 不进 design-system 面板**：面板只收集意图，fx 启用权属主题 G5（主题即决策），五层矩阵选项语义不变（fx 计入 L4 环境层的仪式页特权款，sync-themes.mjs 的 __MOTION_JSON__ 无需变更，实测幂等无改动）。
3. **注意力预算的"每页至多 1 个 fx / 只许仪式页"是文档硬规则而非机器校验**——与 amb/light 族的配给纪律同级（词汇表纪律历来靠文档+评审）；机器可验的部分（参数上限、密度、速度）已全部烧死在骨架常量。骨架未做"非 cover-page 拒绝启动"的硬拒绝，理由：与 `.texture-on` 配给同口径（骨架提供机制，纪律在文档）。
4. **z-index:-1 垫底层**：利用 .slide 的 transform 层叠上下文，canvas 垫在页背景之上、全部内容之下（含非定位文字），生成侧无需给内容补 position:relative——比 guizang 的 `> *:not(.ascii-bg){z-index:1}` 方案更省纪律成本。cover-page 的质感 ::before 层会盖在 canvas 之上（颗粒盖粒子，审美上成立）。
5. **ascii-field 配色取当前文字色**（dark 页即 paper），不绑 accent：字符场是材质不是强调；constellation 取 accent（连线是结构感）。
6. **离屏停帧保留最后一帧**（不清屏）：回屏续播无重初始化闪烁；freeze/编辑态才清屏+摘除尺寸。
7. **cover-uncover sticky 钉住页几何上始终在视口内**（position:sticky 钉在 top:12px，后续页滑过覆盖）——其 fx 按 in-view 语义**不停帧**（页仍"在"视口，只是被遮挡；至多 1 个 fx 的代价可接受）。离屏停帧以普通槽位的收束页验证（T21 口径）。
8. 实现期被 harness 首轮捕获的一个真实 bug：`fxList` 声明原置于动效引擎段，但 `fit()` 在脚本头部即首次调用，`var` 提升只提声明不提赋值——`fxList.length` 抛 TypeError 致整个框架 IIFE 中断（`__pptxMotion` 未定义，T19 连锁失败）。修复：声明上移至 IIFE 顶部（fit() 之前），注释标明原因。
